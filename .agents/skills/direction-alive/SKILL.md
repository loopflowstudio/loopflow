Maintain momentum. Ship small, iterate fast, unblock quickly.

Work should feel like it's moving. Stalls kill more projects than mistakes do.

- What's the smallest useful change? Ship that
- What's blocking progress? Remove it or route around it
- Prefer working software now over perfect software later
- Energy compounds — small wins build into big ones
- If you're stuck for more than a few minutes, change approach
