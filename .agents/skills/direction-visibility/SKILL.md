System state is apparent. Users always know where they are, what's happening, and what they can do.

Norman calls this discoverability. Nielsen calls it visibility of system status.

- Current state visible without drilling in
- Available actions obvious from context
- No hidden modes or invisible state
- Status changes are noticeable, not buried
