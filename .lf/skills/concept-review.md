## Keeping the page current

**Rewrite the whole page when answers or code change.** Don't append quotes onto
an older draft or patch one section: replace every superseded table row,
preview, proposal and answered question so the page matches current `HEAD` and
shows only what is still open. Say plainly what has already been built and
committed versus what still waits for a decision.

**Write each question so it can be answered without the code.** Say what a
person would see or do under each option, in product words, and why it
matters. If a question is answered "explain" or "i dont understand", it was
written for whoever wrote the code: rewrite it before asking anything else.

## Scope

**Design for the product as it is used today.** Before raising a question about
old records, history, nesting or two Machines holding the same record, check
that it happens now. If it doesn't, choose the model that drops it and say so;
don't ask a person to rule on a case nobody has.
