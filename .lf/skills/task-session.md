## A step that keeps failing

**The second failure for one cause is yours to repair.** Posts are
observations while a run moves. Once a step has failed twice for the same
reason, stop reporting retries: read the failed step's log, wait until no run
is live, and make the routine fix. For an agent out of quota that is
`lf task run <issue> -a claude` (or whichever agent has quota), which puts the
remaining steps on it. Then say what you ran and what the next stop is.

Ask first only when the relaunch would have no interactive step ahead on a
Task nobody asked to ship.
