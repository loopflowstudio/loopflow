What to challenge.

The screenshots prove composition. The review should press on navigation, lifecycle truth, and whether the new control density remains calm at real data volume.

Live review checklist

  • Open the Waves chip; walk Wave → Project → Task and verify each column preserves context.
  • Select a Task; confirm drawers retract and Activity scopes to that Task.
  • Press an off Wave or ready Task fader; confirm the actual lf lifecycle path runs.
  • Press a producing fader; confirm stopping does not invent completion or discard Work.
  • Resize narrow and wide; state color must survive even when rate precision and glyphs compress.

Intentional boundary

A red fader currently selects the waiting Work and exposes its reason. It does not open a resolver session yet.

That action waits for the durable Ask queue from blockings. Project and master faders also remain display-only because no agent lives at those levels.
