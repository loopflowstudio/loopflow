- #990 wave chat: make journal delivery failure atomic (+245 -26, 3 files)
  - ## Usage  ```bash cargo test -p loopflow wave::server ```  ## Summary  A journal append that failed used to be logged and swallowed: the runtime still minted the message id, committed the turn to the transcript, queued it as pending, and broadcast it live.
