# Visual Design Reports

Research and audit artifacts for the viz wave.

`VISUAL_DESIGN.md` (repo root) is the design system — the governing document for colors, typography, spacing, and accessibility.

This directory holds supporting material:

- **Visual research** — reference patterns from apps that do sidebar + status + detail well
- **Design audits** — gap analysis between current UI and `VISUAL_DESIGN.md`
- **Polish priorities** — what to fix, in what order

Reports here inform Phase 3 (theming) and Phase 4 (polish) work. See `roadmap/viz/README.md` for the full plan.
