# iOS Improvise UI

Create and trigger waves from iOS/iPad.

## Current

macOS only.

## Build

- AreaPicker adapted for touch (larger tap targets)
- Flow picker for selecting which flow to run
- Direction pills for selecting perspective
- "Run" button triggers non-interactive execution on remote lfd
- No prompt field—mobile triggers predefined flows, doesn't compose prompts

## What's NOT included

- Custom prompt input (Phase 3 chat)
- Terminal view
- Interactive step execution

## Done when

Improviser can create wave, pick area/flow, trigger run from iPhone/iPad.
