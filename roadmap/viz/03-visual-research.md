# Visual design research

No reference material for what "great" looks like. Visual decisions are made without context.

## Build

Research visual patterns from apps that do sidebar + status + detail well:

- **Notion**: sidebar hierarchy, page status, breadcrumbs
- **Figma**: canvas status, collaboration indicators, layer panels
- **Linear**: issue status visualization, priority indicators, sidebar density
- **Arc**: tab management, sidebar patterns, space switching

Focus areas:
- Sidebar patterns (hierarchy, grouping, density)
- Status visualization (running, waiting, error, idle)
- Color usage (accent colors, status colors, background treatment)
- Typography (heading hierarchy, monospace mixing, information density)
- Spacing (section separation, card padding, list density)

## Output

Persistent reference material in `reports/viz/`. Survives PR merges (unlike `scratch/`).

## Done when

`reports/viz/` contains reference material with annotated patterns from at least 3 apps, organized by focus area.
