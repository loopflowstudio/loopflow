Works for all users. Keyboard, screen reader, reduced motion, touch, LLM agents.

Accessibility is not a feature — it's a quality of every feature.

- WCAG-compliant color contrast (4.5:1 minimum for text)
- Focus states visible on every interactive element
- Semantic structure (headings, landmarks, labels)
- Hit targets sized for the input mode (24px desktop, 44px touch)
- Respect prefers-reduced-motion and prefers-color-scheme
- Icon-only controls have text labels for screen readers
