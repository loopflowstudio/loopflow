Run the batch.

## Goal

Take the parallel-safe batch from s2 and launch real work. Each batch item should
leave this step with an execution record: what was launched, how, and what its
initial status is.

## Workflow

1. **Read the batch manifest.** `scratch/vsm-batch.md` is the contract. Launch
   only the listed items.

2. **Prefer lfd-managed runs.** For each batch item, first try to launch through
   lfd so the run is tracked naturally:
   - use `lfq run <wave>` when it can execute the selected item cleanly
   - if the selected item first needs backlog reordering or other prep, do that
     before launch so the run targets the intended work

3. **Fall back when needed.** If lfd cannot launch the specific item cleanly,
   use the direct worktree path:
   - create an isolated worktree with `lf ops wt create`
   - launch the normal roadmap flow in that worktree (`lf ship-roadmap` or the
     wave's equivalent execution path)
   - keep branch, worktree, and PR ownership separate per item

4. **Capture initial status.** For every launched item, record:
   - wave name and roadmap item
   - launch method (`lfq run` or direct worktree)
   - run id, branch, or worktree path when available
   - initial step/status, or the failure reason if launch did not succeed

5. **Emit algedonic signals.** If a launch fails or immediately surfaces a block,
   record it clearly so the next s3 cycle can react.

## Output

Write `scratch/vsm-s1.md`:

```markdown
# VSM S1 — <date>

## Launch Summary
| Wave | Item | Method | Run / Branch | Initial status |
|------|------|--------|--------------|----------------|
| chord-model | 03-wave-discovery | lfq run | run-123 | started |

## Failures / Algedonic Signals
- <wave>: <what failed or blocked>

## Notes
<any launch assumptions, fallbacks used, or follow-up needed>
```

## What to avoid

**Batch drift.** Don't quietly swap in different items.

**Shared execution state.** Every launched item needs its own branch/worktree/PR path.

**Silent launch failures.** A failed launch is still an output. Record it.
