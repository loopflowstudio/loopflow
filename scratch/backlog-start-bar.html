Descriptions

Every builtin Graph on this branch already opens with a comment that reads as a description. Promoting it to a description: key gives the menu its second line without new writing. A shorter line for the menu is drafted beside it.

The installed lf graph list also shows repository Graphs (plan, build, redesign, deep-clean); they would need descriptions written.

Mixed Waves

A selection that spans Waves starts each Task with its own Wave's flow. The button says so: Start 3 · mixed. The menu's top item, checked, spells it out (“Each Wave's flow: feature ×2, code ×1”). Every item under it overrides the whole selection to one flow. Picking one starts immediately, as it does for a single Task.

Your words: “the default should be potentailly a mixture of the tasks are in different waves” and “but you should be able to override that to one”.
