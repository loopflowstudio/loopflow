## Selected concept cuts

- Merge User Name, Account Status, Route Show and PR Status into their one reader.
  Task Changes becomes Diff's files projection without changing its DTO/revisions.
  Skill List joins the catalog; Skill Show and Flow Validate join typed help.
- Merge Run/Exec inventory into Monitor List, preserving paging and Work ancestry.
  Keep active Session discovery/NDJSON and stdin lifetime, ps/top, usage and Work
  activity because they answer different questions. Show resolves Exec/Session;
  raw events and final conclusions require Session evidence. Historical Project
  filters remain until equivalent cross-chapter querying exists. Resume belongs
  to Session Connect; replay remains a separate explicit spend.
- Root `--task` / `--wt` choose location, `--wave` supplies context and cannot
  change Task ownership. Remove `--as`; mode/diff/browser choices each use one
  value option. Query-local filters retain their own meaning.
- Task Run merges into `flow start [template]`: resume the Task's selected graph.
  Named direct Flows still contribute independently. Keep explicit Task Restart
  and hidden Worker for replacement and exact process-claim admission; neither
  duplicates ordinary capture or managed continuation.
- Repo owns connection, refresh and chapter rotation. Delete retired Wave
  Forget/Retire and Chapter-table history. Wave Rename absorbs relocation and
  optional provider title. Keep Wave detail for metrics/Project/Task conditions;
  roadmap owns portfolio planning, including work without execution records.
  `list wave` discovers authored goals without creating placement or Task rows.
- Merge Arm into finite Land: prepare/request auto-merge and return. A request
  is not merged evidence; scheduled/release observation retains its own owner.
- Keep draft publication in PR Open, explicit signal-safe Monitor Prune, current
  exit semantics and operation-specific previews. No universal confirmation or
  authentication-code layer earns a place. These settle the earlier demo choices.

- `wt list --full` is parsed but ignored. `wave status --no-sync` is parsed and discarded. Both delete verdicts are based on handlers, not missing caller strings.
- `wt list --format` accepts arbitrary strings but only recognizes `json`; replace with `--json` and retain the same serialized data.
- `skill show` calls the same definition-help renderer as `help skill NAME`; merge the duplicate operation into typed help, preserving reserved-name inspection.
- `commit --push` duplicates draft publication owned by PR open. Preserve commit-only behavior and compose PR publication explicitly.
- Do not delete required internal installation/process callbacks merely because public help hides them. Exact artifact, worker, Session and process evidence grant different authority.
- Counts include namespace and help entries. Moving nodes does not itself reduce leaf operations; report real deleted arguments/aliases separately at demo.
