Usage: lf <command> | run <name> [message]

lf user  Inspect the current user
lf user name  Show the display name from personal Loopflow configuration or Git
lf :  Run an inline prompt
lf desktop  Open or focus Loopflow.app
lf screenshot  Capture a URL or local HTML file without claiming the user's browser
lf ask  Open a durable session and wait for the user to complete it
lf session  Inspect and continue Sessions
lf session list  List Sessions
lf session open  Open or resume one session in this terminal
lf session complete  Complete a review, blocked Ask, or interactive session
lf session rename  Rename a Session; a human name is never replaced by a suggestion
lf session ready  Mark the active session ready for your review
lf install  Install the latest published Loopflow release from any directory
lf install schedule  Install the latest Loopflow at login and weekly by default (macOS launchd)
lf pr  Pull request lifecycle
lf pr checks  Show CI status for current branch
lf pr status  Show current branch's PR state
lf pr next  After an out-of-band merge, rotate this Task to its next serial PR, carrying committed and uncommitted follow-up onto the new branch
lf pr publish  Publish a ready PR headlessly: push, create or refresh, print state + URL. Opens no review surface
lf pr open  Push and create or update a draft PR, then open its GitHub page. Existing ready PRs stay ready; opening a draft does not publish it
lf pr submit  Prepare a PR to land: rebase, clear scratch, mark ready, and assign it to you. Nothing merges until you click merge on GitHub
lf pr arm  Prepare a PR, request exact-head auto-merge, and return without watching
lf pr land  Arm and watch a PR through CI repair and authoritative merge
lf pr abandon  Abandon branch: close PR, remove worktree, delete branch
lf wt  Worktree operations
lf wt create  Create a low-level sibling worktree
lf wt switch  Switch to a worktree by name, identity leaf, or full branch
lf wt list  List worktrees (read-only; reflects the last-synced main)
lf wt prune  Remove clean terminal or inactive worktrees
lf wt remove  Remove a worktree
lf rebase  Rebase current branch onto target (default: main)
lf commit  Commit changes
lf auth  Provider authentication for local lf skills and ops
lf auth status  Inspect cached credentials and subscription windows; verify explicitly
lf auth disconnect  Disconnect local credentials or one managed login
lf auth connect  Connect local credentials or a managed login using a remembered browser
lf auth set  Edit account configuration or remembered browser choices
lf auth route  Configure and inspect managed account routing
lf auth route set  Replace a provider's ordered route
lf auth route show  Explain configured and automatic account selection
lf release  Release operations (run, check, notes, bump, tag, status)
lf release run  Run the full release workflow end-to-end
lf release check  Check if PRs have merged since the last tag
lf release notes  Generate release notes for a version
lf release bump  Bump version in manifest files
lf release tag  Create a git tag and push it
lf release publish  Stage or publish a GitHub Release
lf release status  Check release workflow status
lf repo  Repository provider administration
lf repo reteam  Reconcile linked Waves to the repository's Linear Team
lf repo webhook  Register or serve Linear webhooks
lf repo webhook serve  Run the receiver that turns Linear edits into Task direction. Reads the signing secret from LF_LINEAR_WEBHOOK_SECRET (source it from Doppler)
lf repo webhook register  Register the Issue/Comment webhook with Linear (one-time). Reads the signing secret from LF_LINEAR_WEBHOOK_SECRET
lf home  Inspect this Home and observe routes to other Homes
lf home id  Print this machine's stable local Home identity
lf home observe  Record the current route for a known Home identity
lf cron  Local launchd jobs that run lf commands on a schedule
lf cron add  Install or replace a scheduled lf invocation
lf cron list  List installed loopflow cron jobs
lf cron preflight  Validate Home authority and declared jobs without changing launchd
lf cron sync  Reconcile installed launchd jobs to match a wave's declared `crons:`
lf cron history  Show durable cron receipts
lf cron trigger  Ask launchd to fire an installed job
lf cron remove  Uninstall a scheduled lf invocation
lf wave  Serve a Wave or rotate its chapter plan
lf wave list  List every wave in the registry (running and stopped), marking which have a live server. Local-only query over the shared ledger
lf wave status  Show one Wave's chapter, Tasks, Runs, and live loop state from the registry. Defaults to the ambient wave (`LF_WAVE_ID`)
lf wave probe  Probe a Wave's Home for liveness and the one contextual action
lf wave connect  Connect a Wave to its Initiative and the repository's Team (Task prefix)
lf wave sync  Refresh shared planning from Linear
lf wave rename  Rename the provider Initiative
lf wave forget  Forget an empty Wave registration, preserving authored files
lf wave place  Place a Wave on a Home
lf wave relocate  Rename or rehome a stopped Wave
lf wave retire  Retire the Wave, retaining history
lf wave recover  Inspect historical Wave Flow work, or explicitly cancel its saved continuation
lf wave new-chapter  Replace the plan, carry started Tasks, and retire unopened backlog
lf wave history  List chapter boundary receipts
lf wave update-plan  Replace the current chapter's KRs, targets, and Flow recommendation
lf task  Linear-backed Task work and bounded workers
lf task checkout  Ensure tracked Task Work and its worktree without starting a worker
lf task run  Start or continue a Task through its saved Flow
lf task create  File a Task in the current chapter; optionally prepare and run it
lf task status  Show durable Task facts and current worker evidence
lf task changes  List files changed from this Task's recorded base commit
lf task diff  Show this Task's patch, optionally limited to one changed file
lf task file  Read one file from this Task's worktree
lf task save  Save UTF-8 stdin with an expected revision and retained recovery files
lf task complete  Complete planning work, or a placed Task whose pull requests are settled
lf task delete  Delete a Task from Linear and reconcile its local record
lf task edit  Edit a Task's title or notes, before or after placement
lf task comment  Read the comment thread, or append direction without starting execution
lf task interrupt  Interrupt the active provider turn
lf task wait  Wait without polling an LM
lf task restart  Stop the pinned Flow and begin a new one in a fresh Task worker; defaults to the chapter's currently recommended Flow
lf tokens  Measure this codebase: lines and tokens per directory (tracked files only)
lf usage  Show direct provider-authored usage from Home-local Run records
lf ci  Show how failed CI is detected, repaired, and landed across this Home
lf ps  Print one parseable snapshot of live Loopflow call trees
lf top  Refresh live Loopflow call trees on a terminal; print once when redirected
lf prune  Reap registered orphan providers and remove dead process receipts
lf doctor  Audit the local run ledger: continuity, vocabulary, attribution, identity, lineage, coverage
lf list  Discover commands, skills, and flows
lf help  Explain a command, skill, or flow without launching it
lf roadmap  Show the current repository's roadmap: every open Task across the repo's Waves, joined to live evidence and bucketed into Now / Waiting / Available / Later. `--wave` scopes it; `--all` spans every repository on this machine. Local-only, deterministic
lf activity  Show one ordered record of durable Work, Run, PR, and Steer facts
lf runs  Show recent agent-backed skill runs with context and token evidence
lf replay  Launch the exact provider request recorded by a prior Run as a child Run
lf reply  Observe wave-chat message(s) and print a reply only if one is warranted. A direct capability: no listener, resident, or governance loop
lf chat  Converse with a Wave; --follow replays its thread
lf ssh  Run lf on a Home or SSH host carrying your local credentials
lf run  Run a definition, preferring a flow over a same-named skill
lf flow  Run or inspect authored flows
lf flow list  List authored flows
lf flow show  Inspect the expanded steps of a flow
lf flow validate  Validate a flow and its review points
lf flow decide  Record a decision for the current Flow boundary
lf flow route  Select an authored branch
lf flow blocked  Open a Session to resolve a blocked decision
lf flow resume  Continue a saved Flow invocation
lf skill  Run or inspect skills
lf skill list  List skills, optionally inside a namespace
lf skill show  Inspect a skill without launching it
