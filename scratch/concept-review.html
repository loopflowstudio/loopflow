One design system: do the product's concepts and the code's line up?

Area reviewed: the whole design system as it stands with this branch (base 2750c9e0fb to 925beb6c52). That covers DESIGN.md, design/, the website's :root tokens, the website pages that still present a design system, and the Swift token source. The Task's outcome is "one design system", so the review asks whether there is now exactly one, with one name for each idea.

Delete internal_pages.py, its three routes and import in website/main.py, and its ruff entry in website/pyproject.toml. Move design/homepage-next/ to design/prototypes/homepage-next/. Move the Work tracking section into swift/README.md.

Why it's safe to do without asking: nothing links to the pages and git keeps them. The released note in release/v0.15.3/NOTES.md that names design/homepage-next/ is a shipped record, so it stays as written. Passed over: keeping the pages as an "internal" style guide. They teach faces that DESIGN.md says neither surface will use, so keeping them leaves a second design system that contradicts the first.

Normal path, failure, recovery

  • Normal: someone adding a website component opens DESIGN.md and finds the step names, then the prototype to match. Today, searching the site for "design" turns up /design first. After the change, nothing else answers.
  • Failure: a token name that exists only on the web (--t-head) gets copied into Swift as Typography.head. The stacked website Task closes this when it moves the web to the language's names.
  • Recovery: if /design turns out to be wanted, it comes back with git revert. No data is lost.

After the build (re-review at ae2be3ee9d)

Every "no" above is now a "yes": internal_pages.py and its three routes are gone (they 404 and leave the sitemap), homepage-next lives under design/prototypes/, Work tracking sits in swift/README.md, and no path outside scratch/ and the shipped v0.15.3 notes names an old location. One mismatch stays on purpose: DESIGN.md carries both The language and Tokens today, and the web still says --t-*. That is the stacked website Task's rename (question 3), labelled as such in the file. Nothing further to change in this Task.
