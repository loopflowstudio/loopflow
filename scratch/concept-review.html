3. Concrete interaction walkthrough (verified normal, failure & recovery)

  1. 1. Normal Find → jump → comment → return: ⌘P finds an unopened file via task.files.find (local or peer Machine), previews it in TaskCodeReader without mutating tabs or jump history, and opens it in Read. Clicking an identifier underlines FileJumps.target; gd / ⌘-click resolves the live buffer first and falls back to task.files.symbols; gr lists whole-word hits via task.files.grep. Comments from Read (.file) and Diff (.diff) merge into one unsent conversation message on ⌘↩, and ⌘[ returns to the call line before falling through to Desktop Back.
  2. 2. Normal Present beside a zoomed Session & rewrite visible HTML: With Session zoomed, lf desktop files scratch/explore.html clears Session zoom while leaving focusedPaneId and Ghostty first responder untouched. Subsequent rewrites of explore.html settle 800 ms and reload in place keeping scroll without raising an Updated · Open banner.
  3. 3. Failure Atomic sed -i scratch writes, wide lines, or failed step comparison: Temporary sibling files are checked against the owning Machine’s live directory listing (reconcileScratchWrites) and dropped before badging; wide lines size the reader’s scroll document to widestLine so cropped Grep hits scroll into view; a missing step base fails only Diff’s step reading while Files’ whole-Task counts and scratch/ stay intact.
  4. 4. Recovery Presentation during Edit or peer disconnect: Presenting while editing adds the file to Open & Scratch and shows the dismissible layout bar (Presented … · Open · ×); dismissing or leaving Edit clears the bar while keeping the queued presentation selectable in Open & Scratch (accepting its line range and mode). On peer watcher disconnect, drafts stay retained in the window until refreshed.

4. Reversible choices made for review

All choices below are built and reversible without data migration (recorded in scratch/questions.md). Reply with e.g. 2b or 5b to steer.

1. Cross-file symbol lookup runtime
  • 1a Chosen: One Tree-sitter runtime (Desktop’s 28-grammar TreeSitterGrammars.xcframework for open-file outline, breadcrumb, and live same-file definitions) plus pure-Rust comment/string-aware declaration matching on the Machine for task.files.symbols.
  • 1b Compile Tree-sitter C/C++ grammars into the Rust lf binary for Machine-side AST parsing.
2. CLI checkout-search surface
  • 2a Chosen: Three peer verbs (lf task find, lf task grep, lf task symbols), one verb per JSON schema.
  • 2b Overload lf task files with mode flags (--index, --grep, --symbols).
3. Legacy lf open --file command
  • 3a Chosen: Delete lf open --file (open/files.rs, desktop::present_files); lf desktop files is the sole file presentation command and lf open is strictly cross-host conversation opening.
  • 3b Restore lf open --file as a thin compatibility wrapper over lf desktop files.
4. Presenting when another pane (Session) is zoomed
  • 4a Chosen: Unzoom the other pane (zoomedPaneId = nil) while keeping focusedPaneId on the terminal so the presented file appears beside the conversation without stealing keyboard focus.
  • 4b Keep Session zoomed and leave the presentation hidden behind it until manually unzoomed.
5. Update & presentation banner lifecycle
  • 5a Chosen: Separate persistent rail badges in Open & Scratch from one ephemeral, ×-dismissible layout banner (suppressed for the file already visible in Files Read, cleared on file switch or leaving Edit, shown on Diff only for deferred presentations).
  • 5b Keep a persistent overlay bar without dismissal until the offered path is opened.
6. Open files when sidebar is collapsed & jump history keys
  • 6a Chosen: Breadcrumb filename dropdown + top of ⌘P + Open & Scratch rail (no second tab strip); ⌘[/⌘] step Files jump history first and fall through to Desktop window Back/Forward when empty.
  • 6b Add a compact tab strip under the breadcrumb when 2+ files are open, or bind file jump history to ⌃-/⌃⇧-.
