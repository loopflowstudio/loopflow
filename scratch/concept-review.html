Proposed implementation direction

Move operation implementations and results below both adapters, removing their old bodies. Trace the production dependency closure before choosing the execution crate’s membership. Keep saved facts in storage, resolved launch settings above it, and command parsing and presentation in the CLI. Add no new Work lifecycle or parallel resolver. A lower-crate-only edit must also refresh dirty build identity.

Normal → failure → recovery

A terminal or Desktop starts the same Task operation and retains its cursor, native thread and input. A lost launch reply retains the creation key and receipt; retry cannot launch twice. Ending a served request cannot stop its detached execution. Preserve request-local directory and I/O, uncertain outcomes, once-only usage and waited landing.

A new root may miss until idle refresh. Refresh cannot interrupt another build; cache failure permits direct compilation. Keep separate targets, correct checkout identity and scripts/dev-lf --isolated-build for source debugging.
