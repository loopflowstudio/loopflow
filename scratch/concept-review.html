Failure, recovery & counterexamples checked

Invalid YAML on disk

No reconnect churn. The server keeps the config.scope stream open and emits SubscriptionFrame(body: nil, unavailable: …). Edits pause while last readings stay visible; fixing the YAML pushes a healthy frame immediately without backoff.

Manual Refresh or scope change during backoff

Immediate recovery. Clicking Refresh or switching checkout, Wave, or target rotates observation = UUID(), canceling the sleeping .task(id:) and opening a fresh stream right away with a 1 s backoff.

Disconnect mid-edit or rapid double-click

No hang, no stale conflict. apply() waits on confirmReading() when the stream lags a frame behind receipt.after. If the connection drops while waiting, observe() releases all pending confirmations before sleeping so the UI never deadlocks.

External file edit while typing

Draft preserved, conflict surfaced. Draft holds the SettingDeclaration captured when typing started. Checked writes refuse stale entries and show Refresh, which calls model.refresh(declaration) to re-bind the draft to the new slot.
