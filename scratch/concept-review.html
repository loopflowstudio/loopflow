Before → proposed experience

Existing removal branch: native Claude/Codex login outside lf; lf account manages six other providers; selected credentials can still be installed remotely. Some read-only status checks also persist CLI tokens.

Proposed, unbuilt: one setup entry shows the connections needed for the selected work. Existing native logins work immediately; optional planning and secrets access is requested only when needed. Command spelling remains open.

Denied consent leaves prior access intact. Expired access offers reauthorization for that grant. A capacity refusal never chooses another account. Connecting must not send an inference request just to prove readiness.

Correction to the PR: “authenticate beforehand” is too restrictive as the complete experience. lf can help complete supported authentication on a destination while removing catalog-driven subscription transfer and renewal.
