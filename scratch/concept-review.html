The one mismatch

make_project_command matches on the tracker. Linear's retry runs the connect flow (Team claim, config write check, inventory refresh) to make one Project; Asana's reruns create, because connect would move the repository to Linear.

Name lf wave create <wave> everywhere: it is idempotent for a live Wave and makes only what is missing. make_project_command becomes a constant format, connect stays Linear's "attach a Linear Project" verb. Small: one function and the message assertions in four tests.

Not taken in this pass: it is a naming choice already listed for review (plan Remains 4), it changes no state or recovery, and connect works as named. Recommended for gate if the reviewer agrees.
