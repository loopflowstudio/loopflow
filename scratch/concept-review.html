Biggest remaining mismatch (outside LOO-1084): RoadmapTask.lifecycle on Desktop

On the CLI and in TaskRow (lf task status --json), an unobserved remote Task already has state: null and never claims to be unstarted. On RoadmapTask (lf task list --json, lf wave show --json, Desktop board), section is working, selection_states omits unstarted, actions is no_action, and runs_on names the remote Machine — yet lifecycle is still a required non-null TaskState carrying "unstarted", because making it nullable is a coordinated Rust + Swift wire change and Desktop badge redesign.
