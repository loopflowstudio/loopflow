Normal path, failure, recovery

Type a draft, detach, rebuild, and resume the same editor. Complete the demo under the chosen disposition, stop verified owners, reclaim eligible runtime, then reopen the same saved conversation.

If storage fails, keep queued input and retry without spinning. When access recovers, deliver it once. If cleanup is interrupted, surviving owners keep their files until teardown succeeds.

Counterexample: copy the transcript and kill the owner while a native request is pending. History survives; the original request does not. Directory separation alone cannot meet the accepted experience.
