The mismatch: store-ahead refusals

Existing behavior

this store needs an lf that knows task_regressed_in (…); install it with `lf install --dev`

A stream flag switches the stream and records it, and refusals name the build to install (both accepted). Following this advice moves a stable Machine onto dev for good.
