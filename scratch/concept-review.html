The repaired mismatch

Before this branch: quiet conversations expired, while an edited draft could hold them indefinitely. Built: open conversations stay resident and the input ledger is gone. Completed-Task closure reads Task completion and current Session membership independently of checkout deletion.

Counterexample found in review: lf session bind <session> --task <done-task> is supported even when that Task has no checkout. Previously no retirement record meant no completed-Task ending. The repair also covers resumption after a finished retirement. The original finding came from code inspection; both cases now have passing transport regressions.

Use it, lose the connection, return

Leave a draft in an open Task and close its viewer. Return to the same provider. Complete the Task and leave again: after the fifteen-minute viewing grace, cleanup can end it once live work settles. A returning viewer cancels cleanup.

Covered by regressions; still to demonstrate: repeat with a done Task that never had a checkout, then with a conversation resumed after checkout retirement. Both follow the same closure rule. A finished deletion cannot exempt a new running conversation.

A locked store cannot stall typing or authorize closure. The owner retries the judgment after recovery without replaying input, rechecking Task reopening and viewer return. Provider history and a saved screen remain; the unsent editor is lost.

Counterexample kept: a missed hook can hide an active turn. Output arriving after the cleanup judgment invalidates that judgment. The output check remains; the idle timer is gone.

Words people will meet

A done Task's conversation ends after the viewing grace once live work settles, whether or not the Task has a checkout. Returning afterward continues from saved history; it does not reopen the Task. Checkout deletion is a separate cleanup effect. docs/sessions.md describes this behavior.

The demo skill now waits for live work, quits each demo provider and joins its processes before removing the runtime root. Quitting the app alone is insufficient. History stays.

Built: Wave and repository conversations follow the open-Task rule. Bare owners also remain until quit during this transition. The ignored end_detached_after key and unused database column remain only for release compatibility and staged removal.

Proposed, unbuilt: bare-direct launch and resident-limit suspension. LOO-824 supplies the planned emulator; reading an empty editor from it has not been chosen. Nothing here adds a replacement ledger.
