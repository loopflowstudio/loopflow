Proposed source contract

Application acquisition and policy → synchronous storage → saved records. Keep request/compacted arithmetic with TurnContext; make hear(&mut TurnContext, &ConversationEvent) an application function. No extension trait or storage callback into launch code.

Keep non-exhaustive enums. Move string conversion, saved keys and location text with their records. An unsupported scope returns a dispatch error; unsupported recovery uses the uncertain-receipt path; unsupported landing holds delivery; an unsupported PR phase recommends NoAction. No panic, launch, completion or invented JSON fallback follows an unsupported value.

Normal → failure → recovery

A shell’s lost acknowledgment still leaves a consumed receipt. Retry discovers it rather than launching again. An uncertain creation retains its identity and inspection path. Capture history still validates the complete manifest; activity still stops before reading older evidence.

A migration-directory move keeps each slug’s first merge position, timestamp and exact SQL. Refreshing only origin/main must update the generated catalogue. An interrupted upgrade retains the same transaction, exports and refusal policy. No new recovery lifecycle is proposed.
