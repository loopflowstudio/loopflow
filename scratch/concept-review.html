Checked against the accepted design

  • No updater on dev (slice 7, kept per the Task's direction): the only replacement path is promotion, which already handles a running app.
  • Same checks as a release DMG: codesign --deep --strict and spctl before promotion; an unsigned image is refused (test).
  • Credentials in Actions: the Task directed GitHub secrets from Doppler; the README's “GitHub is credential-free” line now names the exception.
  • Recovery: a failed download, verify or promotion leaves the installed lf and app in place; the image detaches on drop.
