Normal → failure → recovery

Unchanged B reuses A’s libraries; editing an owner invalidates its dependents. B must still execute as B. A missing cache falls back to ordinary compilation. An unknown root may miss while another build runs; it must not restart that build’s daemon. Deleted A can leave stale debug paths: rebuild B with the isolated command.

A disconnected planning read must retain uncertain and conflicting deliveries. Moving quota normalization only to new writes would mishandle historical rows; read-time reconciliation must survive. Served reads retain their SQL snapshot, external revisions and deadlines. No new Work record, migration or conversation lifecycle is needed for these crate boundaries.
