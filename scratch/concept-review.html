Built usage: Start continues the Task’s Workflow. Auto-Ship requests the remaining delivery steps; Stop Auto-Ship requests withdrawal. Feedback appears immediately and survives disconnected restart. Successful dispatch clears the request without promising a running Graph, merged PR or stopped Process. Both app READMEs describe this distinction; no builtin skill change is needed.

Failure and recovery: a save failure offers Try again. A lost reply keeps the original Machine, ID and exact command; Check request looks up that outcome without another submission. A finished failure releases ordering while remaining inspectable: it cannot assert rollback. Generic dispatch has no domain-authorized replay after a crash.

Counterexamples: Stop behind an uncertain Auto-Ship cannot promise immediate withdrawal. A finished Stop cannot certify Process exit; independent Graph work may still be Moving.
