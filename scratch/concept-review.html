“Repeat this pass.”

The reply belongs to one visit to the breakpoint. Its saved loop already knows which build to repeat. The Task applies the chosen decision there and carries the reply to the next worker. A deliberate request to start elsewhere still uses --from.

What survives a closed conversation?

Finish and park

The worker finishes. The carrier saves the cursor at the marker and the producing step, then relinquishes ownership in the same write. The breakpoint launches zero processes. Auto and batch take the saved default directly.

Reopen and discuss

The Machine wakes the primary for this arrival. If launch fails, the Task stays ready and its result remains readable on reopen. A missing provider transcript can fall back to the saved turn. Missing artifacts are identified by path.

Continue once

The run action compares the arrival, saves accepted direction and installs the next cursor together. A worker launch failure can retry there. A competing continue sees where the Task moved. A question or a closed pane leaves the visit open.

Counterexample. Auto carries pass one through the marker. Pass two stops at the identically named marker before a delayed “2b” arrives. Comparing the marker name would accept it. Comparing the visit leaves pass two untouched. The old words remain visible in the conversation.

A blocked default retains its reason. A leading break or a direct jump to a marker has no finished worker to quote and shows its forward destination. A legacy Task parked before an interactive worker still runs that worker on its next continuation. LOO-1100 covers retiring the old reader. Idle Antigravity wake belongs to LOO-1098. Until then an open idle Antigravity conversation receives pending input at its next turn.

Choices for review

  1. If you pick “fix it first”, how should build resume?

    1a · Chosen. Repeat the current build pass with your reply. Keep the branch and earlier pass count.

    1b. Start build again from a named step. This gives you a fresh start and requires identifying which build you intended.

  2. If a reply arrives after its review has passed, what should the conversation do?

    2a · Chosen. Show where the Task is now and leave your words in the original discussion. You can give fresh direction if they still apply.

    2b. Show where the Task is now and immediately ask whether to send those same words to the current work. This adds a decision each time an old reply arrives.
