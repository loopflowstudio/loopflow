Failure and recovery

If the host stops answering, retain the previous display as stale and retry after reconnecting. Unavailable planning is not an empty board; unknown Session liveness is not death. A missing named record produces a not-found error.

A newer Graph run does not replace the primary conversation. Checks carry their observed head and time. The control holder names the recorded occupied terminal; it grants no input authority. The preview retains its source and time.
