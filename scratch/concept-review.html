Try to break the model

Normal: the request stays visible until the admitted Session is usable. Current Task data ends launch-specific routing rules.

Failure: a saved creation with failed attachment still offers Retry opening for that same Session. An unsaved request offers Edit request; an uncertain submission keeps its UUID.

Recovery: closing after save uses the existing journal. Navigating away prevents a late reply from taking focus. A later legitimate no-Graph Task uses ordinary UI after launch reconciliation.

Completion counterexample: the command succeeds but refresh fails. Restoring the row as though completion was rejected would contradict the saved result. A later selection must also survive failure recovery.
