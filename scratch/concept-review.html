Walk the proposed behavior

Normal

Ops is renamed Product while the draft is open. File still saves to the same Wave, and the brief opens in Product. Start with Use default resolves the existing Wave's current default and opens the admitted conversation.

Refusal

Ops is removed and somebody adds a different Ops. The stale draft gets a refusal and keeps its words and workflow. Choosing the new Ops or the repository is a deliberate edit. If the selected workflow vanishes, Use default is still one edit away.

Recovery

Lose the answer after commit. Recovery follows the receipt to the same Task. If the Task was later deleted, recovery reports that it is gone. Lose the connection before commit, then replay after removal. A confirmed refusal makes Edit draft available with the original words and choices.

Counterexamples covered by the plan. A replacement Wave with the same name has a different ID. A receipt can outlive its original destination.
