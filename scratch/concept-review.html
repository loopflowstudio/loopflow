The mismatch weighed: one allowance, two files

A pause is just a budget with nothing left until reset, so folding the cooldown deadline into the budget record would mean one lock per request instead of two.

Rejected. The installed release of lf reads locks/linear-cooldown/<key> to honor a pause. Move the deadline and an installed lf keeps sending through a pause, which spends the shared hourly budget this Task exists to protect. The cooldown stays the pause authority, and the budget extends it.

Reads still forced past the window

  • Cold acquisition of a Task that isn't stored yet: there's no local state to serve.
  • require_outside_current_chapter: chapter rotation needs current Linear state before it moves work.

wave status reaches Linear only through sync_repository, which the window absorbs. Desktop monitoring reads the store.
