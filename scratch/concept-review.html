No further concept change needed

The accepted experience remains coherent: add a usable Wave, rename its address, or remove it while keeping existing work and history. No product decision is awaiting Jack Heart. This review leaves implementation unchanged.

The consequential mismatch, now addressed

Previously, a missing Wave directory or an already-matching Git commit could be mistaken for finished cleanup. A retry could forget an archive obligation or leave staged residue behind.

Implemented now: the original request retains its identities and unfinished effects. A Wave leaving navigation does not erase the work needed to finish its removal.

Open Tasks move to parent/repository. Chapters and conversations remain in history.

Then remove: Task membership changes → retirement → archive → authored cleanup.

CLI-only --delete-backlog explicitly deletes unstarted Tasks. Started Tasks always move. Re-adding a removed name creates a fresh identity.

Failure and recovery

lf wave remove ops
# Wave retired; Linear archive failed. Files remain pending.

lf wave remove ops
# Retry the captured Initiative and authored changes.
# A reused name does not redirect this unfinished request.

Command failures retain a Retry action. Partial receipts keep the explanation visible with Done; their CLI retry remains available after the row disappears. Bare-word prose mentions are advisory and are never rewritten automatically.

For a commit followed by a failed index reset, repeating the command reconciles the saved index entries even if HEAD already contains the change. Later staged edits and replacement Waves remain intact.

Ownership: planning owns Wave and Task state; the Machine-local operation journal owns unfinished effects. Desktop renders the shared receipt. Neither the journal nor retirement needs another user-facing management action.

Review questions, settled by the accepted design

  1. Does removal delete started work? No. Started Tasks move; only explicit backlog deletion removes unstarted Tasks.
  2. Does a hidden Wave mean cleanup finished? No. Retained effects and the receipt establish what remains.
