Follow the handoff through

Model: one shared presentation owner per Machine/account; per-window or route navigation. One intent carries its original Machine, command, operation ID and ordering token before any await. The actor owns disk and confirmed query preparation. No per-view removal sets or second outbox.

Persistence: save in gesture order before send. Adopt by operation ID only when the store publication includes the durable effect or its established resolution. Never remove the transient layer first or add a duplicate delta. Save failure removes only its unsaved effect, retains command/error and does not reselect. A crash before save may lose unsaved intent; nothing may have been sent.

Queries: store changes publish to mounted lists even without a new network frame. Open/close leases are separate from stored query identity; closing one of two same-query windows must not blank the other. Returning filters apply current effects before cached display. Inspection keeps confirmed DTOs and exposes projection separately.

Recovery: existing per-query stage fences, supersession and epoch rules remain. A replacement epoch cannot authorize replay; an old prepared publication cannot replace newer intent. Native owners still establish input readiness. Coverage retention must not keep a resolved execution lane blocked.

Migration: wire both production completion paths into the shared owner, replacing Desktop's command-waiting action and adding mobile completion. Preserve explicit retained destinations. Continue exhaustive effect declarations, remaining recovery/resource lanes and deletion of checkpoint/presentation exceptions; this handoff does not complete the whole migration.

Docs and skills: usage above remains proposed until both clients consume it. Existing recovery skill guidance stays. Native latency benchmarking remains outstanding; these consistency checks do not measure paint or input.
