One interaction, as built

$ lf wave create ledger ; lf task create --wave ledger 'x'
$ lf wave plan connect ledger 'Ledger'     # links the Wave's Project
$ lf wave rename ledger books              # Project name follows; Linear gets a project_name action
$ lf wave status books
  Project   books (linked) · started
$ lf wave status books --json | jq .project
  {"state":"ok","value":{ … one Project … }}

Failure and recovery: an unreadable store gives {"state":"unavailable","reason":…} and Desktop says the Project did not load; a Wave that arrived from a released build reads value: null (Project none) until its first Task makes its Project.
