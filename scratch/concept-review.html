One operation across CLI and Desktop

The shared binding operation commits association, primary selection and the requested directory together. Desktop uses it too. Other conversations remain associated. Historical attribution and permanent conflicting bindings remain intact.

Before: Task T owns checkout A; chat S is in B
Bind:   T opens S; S requests A
Now:    live client and unsent input remain in B
Next supported connection: same S and history, actual provider cwd A

Files in B stay there. A failed connection retains the pending destination. Retrying the same binding must not duplicate work or discard the request.
