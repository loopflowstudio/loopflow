Actions → concepts → APIs (as built)

A person rebuilds lf or removes a worktree. The Session owner running that build stats its canonical executable every 2 s from its one lifetime thread. Once the file is removed or replaced and the owner waits for a person, it tells attached viewers and signals itself with libc::kill; the exit is recorded.

$ lf resume session_…        # attached, idle; worktree build relinked
This Session's lf build was replaced; `lf resume session_…` reopens it.
$

One owner, one executable identity, one end path. Installed lf-<digest> owners survive lf install. The first pass's mismatch (silent exit for attached viewers) is resolved through the existing Response::InputHint.
