Round 7: one interaction, walked

Normal path, System mode. Both sections show. Fjord Light is ringed in the light grid, Signal in the dark grid; the headings read “Light themes · Fjord Light” and “Dark themes · Signal”. The person clicks Fjord Light, then Signal. The bar at the bottom reads Customize (and, for a theme of yours, Delete). Which one does it act on? The window's own colors and the small “Previewing Signal” line at the top say Signal; the two rings say nothing, because both are rings.

Failure. The person wanted to customize Fjord Light, last seen ringed, and presses Customize: the editor opens on a copy of Signal. With your own theme on each side, Delete deletes the one whose side was clicked last. Recovery is Cancel (nothing is written before Apply), but the person learns the rule by tripping on it.

Before round 7 the buttons sat under the card they acted on, so place said which. Moving them to the bar (Jack's “i also dont like how the Customize button makes the rows jump”) was right; it dropped the one cue that told the two chosen themes apart.

Biggest mismatch: a notice that can't tell a bad choice from a server that didn't answer

This change made the theme a question Desktop asks its server. That added a failure the old file read never had: the server can refuse the question. The store still has one slot for “something is wrong with your theme”, and the banner's one button assumes the person's choice is at fault.

Recommendation (made for review): split the slot by who can fix it. notice keeps what Choose Theme fixes (unknown names, unreadable files). A failed read becomes its own value, shown in the banner without the button. When the server rejects the request's shape, ServerLink names both builds, the mirror of unreadable: “The server (0.16.0) can't read what this Loopflow (0.17.0-dev) asked. Update the older one.” No revision bump and no fallback request shape: the repo carries no old-version support, it says which side to update.

Passed over: bumping the revision (the client sends min_revision 8, so it wouldn't refuse old servers, but nothing would then branch on it without a compat path); quiet fallback to Loopflow's pair on Desktop as on the phone (Desktop would then draw the wrong theme with no word why).
