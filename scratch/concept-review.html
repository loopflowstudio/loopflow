LOO-1061 · Concept review

Mac terminal appearance

Do the product’s concepts and the code’s concepts line up? This review compares the base and the built change across terminal text, personal font settings and the Appearance chooser.

Regular text can look like emphasis

Open either pane and read ordinary output at the font’s native weight. The running program chooses bold and italic. Set font-thicken = true in personal Ghostty settings and reopen Loopflow to add stroke weight to both panes.

Keep the built change. Removing the app’s override addresses the heavy strokes at their source. A different face would alter glyph shapes and fallback, and lowering the strength would still enable thickening. The Ghostty option keeps extra weight available through the same personal configuration that controls font family and size.

Try it in a pane

Start with the branch default and a personal configuration with no weight setting.

  1. Read the output

    Read regular, bold and italic text. Preview Dark, then Cancel. The palette changes and returns while Ghostty keeps the same font settings.

  2. Put the option in a theme file

    Import a valid color theme with font-thicken = true. The import lists the omission. Its colors preview while ordinary text keeps native strokes. An unreadable palette leaves the last valid colors in place and disables Apply.

  3. Move it to Ghostty config

    Apply the color theme. Set font-thicken = true in personal Ghostty config and reopen Loopflow. Remove the line and reopen to recover native strokes with the saved palette.

Mounted QA captured Task shells in Light and Dark and checked the personal setting after relaunch. Automated checks cover Appearance persistence and cancellation, import omissions, invalid colors, and the effective weight across themes. The mounted Session had no sample text, and the screen locked before the run could exercise live chooser actions. Those two mounted checks carry forward.

Repeat the interaction with an explicit true and a personal font family. A palette change that flips the setting would break the shared baseline. If a family still looks too heavy with thickening off, compare at the same size, display scale and palette and inspect the selected face.
