Outside this work

Run in Xcode still bundles a branch lf (cmd_bundle_control_tools), so that build is .bundled and starts a server. Ending it needs debug builds to stop bundling while release and CI keep it.

Any Desktop attaches a viewer to each retained workspace's Session, and a narrower viewer resizes the shared terminal. The release app does the same. A view that doesn't size the terminal is its own outcome.

One unreproduced first-entry crash in a live Session pane, in code this branch doesn't touch.
