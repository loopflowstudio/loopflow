Normal → failure → recovery

Unchanged B reuses A’s libraries; editing an owner invalidates its dependents. B must still execute as B. A missing cache falls back to ordinary compilation. An unknown root may miss while another build runs; it must not restart that build’s daemon. Deleted A can leave stale debug paths: rebuild B with the isolated command.

A disconnected planning read must retain uncertain and conflicting deliveries. Moving quota normalization only to new writes would mishandle historical rows; read-time reconciliation now survives in the account owner. Two simultaneous launches must not rank old candidates and then blindly stamp their choices. The selection commit must detect changes to every saved fact used in ranking, including other candidates and intervening selections.

Served reads retain their SQL snapshot, external revisions and deadlines. Observing ignored configuration after the local lock releases must still invalidate the watch; reaching a quiet deadline must update it without a store write. If the first row is dead or unknown and the next is live and available, limit=1 must return the next row. Filtering an already limited page would hide it. A quiet deadline must recompute page membership as well as displayed availability; Task selections must agree. Observe outside the connection mutex, retain the pinned reading, and avoid loading every full summary to fill a page. No new Work record, migration or conversation lifecycle is proposed.

If a PID is reused or another resume replaces an attachment, unknown identity remains unknown and the old attachment cannot retire its replacement. Extracting storage must retain the attachment lock across observation, close, settlement and claim. Keep the native thread and pending input.
