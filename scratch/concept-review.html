Counterexamples that held

  • A Dashboard's focused tile is the selected Work, so "in place when not selected" would have left the Dashboard; the proposal keeps "a board is presented", which boardPlan already maps for every board.
  • An entered tile (.entered) is full Work, not a tile; its Retry navigates, unchanged.
  • A closed selected Task's button readmits it: the link route reaches focus(deliberate: true), which clears the closed key, and WorkspaceRetentionTests covers Close then a deliberate reopen for a Task and a primary.
  • An unknown Machine never shows a gate: SessionsRootView renders "Workspace unavailable" or progress instead of the content, so the placeholder's generic note cannot appear there.
  • A Wave's machine is its Tasks' default Machine, not where its primary lives; prefetching every visible Wave's primary in the local checkout is right.
  • The pane overlay's Retry above panes that already show labels the same failure the same way and runs the same opener; no second route.
