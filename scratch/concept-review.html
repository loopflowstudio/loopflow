Advance with the existing design

No product decision is needed. Session panes keep the same connection controls; quiet mailboxes stop scheduling reads. This is implemented behavior, with QA and gate still ahead.

Before → implemented

Every pane reads its mailbox ten times a second → each surface watches its mailbox directory and reads on change. Retained hidden panes remain current.

The mismatch was idle work: retaining a conversation also retained a polling loop. Observation now follows mailbox changes without adding a setting or action.

Failure and recovery

Reconnecting… pauses input and retains the last screen. Exhausted recovery offers Retry. Recovery can return a read-only pane; Move here requests control once, without replaying an uncertain takeover.

Missing or malformed status keeps the last valid reading; a later atomic publication updates it. Bursts converge on the latest reading rather than replay every transition. The mailbox is temporary presentation state; the wire format, relay, Session persistence and execution ownership stay as they are.

Counterexamples the design must handle

A file watch loses later replacements, so watch the directory. A hidden-pane pause leaves status stale, so retain observation. A queued event after Close must neither notify the pane nor recreate its mailbox. Existing focused tests cover replacement, recovery, acknowledgement and closure; mounted UI behavior remains for QA.
