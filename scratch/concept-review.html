Bind the conversation.
Set its directory.

Jack Heart accepted immediate Session cwd selection. Binding permanently associates an unfinished interactive Session, makes it primary and sets its directory to the Task worktree. Already-running clients may retain their original directory. Files and input stay intact.

ActionResultCommand
Create around this chatAdopt the exact conversation and its existing work.lf task create --session SESSION --title "Finish prototype"
Select the Task conversationBind permanently, make primary, select the Task directory.lf session bind SESSION --task TASK
File separate work and startCreate and run a new Task without implicit adoption.lf task create --title "New work" --run

Same-worktree subdirectories survive. Open unplaced Tasks adopt unowned linked checkouts; main and Wave checkouts stay shared. Done Tasks stay done and acquire no checkout. Conflicting permanent assignments stay intact. Creation and binding alone start no Graph.
