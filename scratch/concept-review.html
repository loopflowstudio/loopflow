The biggest mismatch

None left inside this work. The one the last review named, one name (forward.env) for a required secret and a login, is resolved as built:

Before

lf --machine mini -a codex …
Error: forward.env names
 CLAUDE_CODE_OAUTH_TOKEN, which has
 no value on this Machine

Now (built)

lf --machine mini -a codex …
mini has no Codex login; run
 `lf machine login codex mini`
Choice made for review. lf machine logout claude mini keeps running claude auth logout there. Logout acts on a Machine's own state for every provider (Asana and Doppler run lf machine logout there), and refusing it would leave no lf way to clear a hand-made login. Stopping forwarded launches is forward.env's job. Passed over: refusing it like login.

Larger than this work
