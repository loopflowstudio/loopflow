The consequential mismatch

Before: Background scheduling and separate 10/30-second process-inspection limits could prevent the hourly cleaner from inspecting any candidates during build contention.

Implemented: Standard scheduling and the existing two-minute command limit, capped by the run budget. Eligibility and ownership rules stay intact.

Successful manual execution is evidence of a working path. It does not establish reliable calendar execution or sustained containment.

Failure and recovery

Unknown or surviving owners preserve output and produce a failure. The lock releases; the next scheduled run obtains fresh evidence. A reparented process with no discoverable relationship cannot be stopped on repository ancestry alone.

Source, durable history, reserved project data and active dependencies survive. Partial removals receive no allocation credit. Missing measurements remain unknown.
