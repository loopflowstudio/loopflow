The mismatch, before and after

Before: a write returned arbitrary JSON beside an independently declared schema. A client could receive a shape the schema did not describe.

Implemented: one declaration supplies the Rust result type, dispatch variant and x-result. The server serializes the result without adding a tag. Engine child-command builders also feed Clap checks.

Normal use and recovery

  1. Submit task.ship; decode shipping, already_shipping or at_end. Follow the existing Task and execution references.
  2. If the reply is lost, the write may already have taken effect. Inspect existing state; the carrier does not replay locally. A request trace does not replace the execution owner.
  3. Disconnecting leaves admitted work running. Typed answers do not introduce rollback, a new stored lifecycle or a persistence migration.
