The concepts underneath: a Session (one ongoing conversation), the thread it currently uses (provider conversation; replaceable, kept in history), the holder (whoever is running that thread now), and for Tasks, an owner (person on a Machine, mirrored as Linear assignee).

The mismatch

Stopping a step's agent makes the step fail. lf task run only holds back when the Task has an interrupt event, and takeover writes none, so the route starts again (attempt 2 of 3) in the same worktree while you type to the step's old thread. That puts two agents in one checkout, reached by a bare lf resume.

Read from code, not demonstrated. To confirm: lf resume <step session> during implement, then lf graph list --for-task.

a. You take the work. Resuming a step's Session records an interrupt:
   the Graph stops, no retry, you continue on the step's thread.
   The next lf task run starts that route again.

b. You get a fork. For a step's Session, resume behaves as --fork:
   the Graph keeps going and you talk to a copy seeded from its log.

c. Today. The step dies, the Graph retries, two agents.

Giving up a Task: hold → assignment

Jack Heart's direction: no deferred state, only assigned or not. Starting assigns, unassigning clears Linear.

lf task claim LOO-618      # you own it; Linear assignee = you; operators may move it
lf task unassign LOO-618   # nobody owns it; Linear cleared; nothing moves it
lf task run LOO-618        # claims if unowned, then runs

What exists: task claim/unclaim already exist. Claim sets the Linear assignee; unclaim leaves it. task edit --assignee/--unassign sets the same field a third way. Deferred is a separate bit read by task run (refuses), ship (stops), CI repair and Wave operators (skip).

What changes: operators already leave unowned backlog alone, so unassigned covers what deferred did. task run on an unassigned Task claims and goes instead of refusing. Ship and CI repair check for an owner. The lost case is "mine, but leave it alone". Under this model you unassign, and Linear shows that honestly.

Deleted: hold/release, TaskState::Deferred, set_task_deferred and its peer event, edit --unassign. About 25 files plus Swift and skills.
