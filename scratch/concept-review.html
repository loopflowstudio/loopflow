The one loose end, now closed. Jack's decision moved "history's settling of dead Process rows" to a write path. There is nothing to move: a dead Process is derived on every read from its receipt and OS identity (journal::recorded_process_evidence) and never written back. If some read did write, the read-only store would refuse it, so the failure would be loud.
