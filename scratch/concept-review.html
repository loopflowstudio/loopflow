One interaction, including recovery

Set default → launch at standard speed → change the conversation to priority → reattach and keep priority. If Codex dies, resume restores native history and applies the current launch preference; it does not replay the interrupted turn.

Counterexamples: unset at repository scope can reveal a global preference. Replay with no captured override still inherits today’s provider configuration. A conflicting invocation override on live attachment must not reset the conversation.
