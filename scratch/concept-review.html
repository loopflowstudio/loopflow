  1. 1. Normal Open large file → drag-select → ⌘-click definition → comment → Back: Opening WorkModel.swift (3,766 lines) shows plain text in <20 ms and applies Tree-sitter colors asynchronously. Dragging across lines 3748–3750 selects and copies cleanly. ⌘-clicking scopeName handles the click directly in mouseDown (no modal tracking loop), scrolls to line 3740, and highlights line 3740 so the declaration stands out even near EOF.   2. 2. Normal Peer scratch write & Back to rendered Markdown: While editing src/Calls.swift on a peer Machine, an agent rewrites ignored scratch/report.html via atomic rename. TaskFilesWatch updates scratch_pages without bumping revision: Desktop skips git diff, badges scratch/report.html in Open & Scratch, and shows Updated scratch/report.html · Open ×.   3. 3. Failure Oversize (>1 MB) file, peer disconnect, or missing symbol: Opening 2 MB src/huge.rs checks file size before buffering 1 MB of non-binary text in observe::Cache and shows a labeled loading state until File exceeds 1 MB · preview unavailable arrives. A peer watch disconnect preserves seenScratchStamps and drafts; zero definition hits leave scroll position and selection untouched.
  4. 4. Recovery Reconnect after coalesced peer writes & editing recovery: When the peer server reconnects after three scratch rewrites, the next TaskFilesRevision frame’s scratch_pages stamps differ from seenScratchStamps, surfacing every updated page without losing events. Switching to Edit still uses TaskFileDocument.editor with retained caret, Undo, IME composition, and 3-way merge.
