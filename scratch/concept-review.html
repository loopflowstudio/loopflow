Biggest mismatch

Which side a theme belongs to has two rules: import reads the theme's colors, a card click reads picker. The theme already knows its side. proposed Use that everywhere and the side-selection verb disappears.

Built

// card
appearance.showPicker(side)
appearance.previewTheme(entry.name)

func showPicker(_ appearance: AppearanceMode)
func previewTheme(_ name: String)   // side = picker
func importTheme(_ url: URL)        // side = file.isDark
private(set) var picker: AppearanceMode

Proposed proposed

// card
appearance.previewTheme(entry.name)

func showPicker(_ appearance: AppearanceMode)
func previewTheme(_ name: String)   // side = theme.isDark
func importTheme(_ url: URL)        // read file, then the same assignment
private(set) var previewSide: AppearanceMode

Written into scratch/plan.md, Remaining 1–2. Nothing a person sees changes; the store loses a verb and a way to put a theme on the wrong side, and the README stops describing a refusal that's gone.
