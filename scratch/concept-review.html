The distinction that must remain

Release is not job settlement. A Rex server can exit while native jobs survive. Its adapter must establish their settlement separately. Desktop's surfaces can disappear while its destination-owned shells continue; those owners still prove cleanup.

Missing routes, expired leases and failed reads cannot establish exit. Remote observation uses an existing route from the execution Machine back to the retaining Machine. Reconnection can supply fresh evidence; it never replays commands or silently starts a local prompt.

What the usage guide says

Quit Desktop to leave shells running. A completed, released Task can clean up after fifteen minutes; eligible idle agents use their two-minute rule. Requested work finishes first. Confirmed exit can release a crashed Desktop instance without relaunch. Lost contact leaves cleanup pending until its state is known.

Cleanup discards eligible uncommitted checkout files, preserves committed-ref safeguards, and retains Task and conversation history. Close ends an ordinary shell and its jobs once protected work settles. Undo restores its identity and history; New Shell deliberately starts fresh execution. Deleted checkouts are not automatically recreated.
