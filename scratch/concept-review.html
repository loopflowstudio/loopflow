5. Open questions for review

Reply with a number and letter (e.g. 1b) if you want any choice reversed before landing.

1. How should a woken steer appear inside an idle Antigravity terminal?

Antigravity 1.5.16 does not give hooks or local callers a way to inject background messages into a running TUI without installing a global sidecar into ~/.gemini/config.

  • 1a (chosen for build): Paste the steer directly into Antigravity's held terminal and press Enter — it looks like a pasted prompt in the TUI, starts one turn, and touches no global ~/.gemini config.
  • 1b: Install a Loopflow sidecar into ~/.gemini/config so wakes arrive through Antigravity's own agent API instead of typing into the terminal (means lf edits global Antigravity config).
2. If you start typing a draft in Antigravity and then backspace it all away, should an arriving steer wait for your next Enter?

Without screen-scraping Antigravity's TUI prompt box, Loopflow knows you pressed keys but cannot tell whether you backspaced all the way back to an empty line.

  • 2a (chosen for build): Yes — hold off automatic wakes after any typing until you press Enter, Ctrl-C, or Ctrl-U. Never risks submitting a half-typed prompt; your next Enter still delivers the waiting steer.
  • 2b: Try to read Antigravity's prompt line from the virtual terminal screen to detect an empty box (allows waking after backspace, but breaks whenever Antigravity's TUI layout changes).
3. Should the parity table track real-provider-only interactive gaps like viewer handoff (LOO-1097) alongside automated behaviors?

Automated tests run stand-in scripts and can prove 12 of the 13 behaviors on every harness, but cannot reproduce a bug inside the real agy binary's TUI.

  • 3a (chosen for build): Keep all 13 in one generated parity table, clearly marking 12 as automatically verified across every harness and 1 (ViewerHandoff) as real-provider-verified with owner LOO-1097.
  • 3b: Limit the generated parity table strictly to the 12 behaviors automated tests can prove, and track real-provider TUI bugs only in Linear.
