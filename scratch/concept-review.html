Normal path, failure, recovery

Normal: the laptop's choice selects Codex without an extra launch override. Origin-authored skill and occurrence preferences travel with their targets and choice/fallback meaning. Executor-local bindings stay local.

Failure: a remote preference edit or deletion prevents automatic retention. Forwarded execution still uses the incoming profile. Missing definitions or matching occurrences remain retention conflicts; missing referenced assets retain an actionable preparation error.

Recovery: explicit adoption edits preferences in an existing definition while preserving instructions, topology, comments and native fields. It neither installs a skill bundle nor promotes a fallback into a choice.

Counterexamples retained: direct executor work must still use its own policy; repository choices must still beat origin fallbacks; captured instructions must keep executor-local settings; composed and repeated Graphs must keep their authored occurrence addresses. Removing all definition metadata or elevating the profile to CLI authority would violate these requirements.
