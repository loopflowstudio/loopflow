Usage documented in the guides

Quit Desktop to leave shells running. Completed Tasks retain their shells and checkout through the fifteen-minute absence grace; eligible idle agents follow the two-minute policy. Cleanup can finish while Desktop stays quit. Explicit Close skips grace after work settles. If release never reaches the destination, cleanup stays pending. Reconnect reuses surviving execution; New Shell starts fresh.

Normal, failure, recovery

Normal: an acknowledged away release preserves the existing deadline. After requested work settles, destination owners and native hosts each prove their own cleanup. Task and conversation history survive.

Failure: a retained lease expiring without a release leaves checkout cleanup pending. A lost reply is different: the caller is uncertain, but a committed release still counts. Retry the identical revision safely.

Recovery: a newer retained observation clears native settlement and cancels pending retirement. A delayed old report cannot undo that return. Cancellation between cleanup passes cannot roll back effects already performed.

Review questions and dispositions

  1. Does quit mean explicit Close? No. Jack Heart accepted retaining ordinary shells on quit. Departure with grace is implemented.
  2. Does release prove native cleanup? No. Record settlement separately; Desktop and Rex have different native resources.
  3. Does missing acknowledgement mean closure? No. The caller's result is unknown; the destination retains any observation it committed.
