Failure and recovery

If only the child defines work, inspecting outer/work must report no matching step. Inspect inner/work to find that child's preference. Unsetting a preference reveals the next source and preserves shared definitions, occurrence origin, conversation history and account attribution.

A conversation's explicit agent remains local to that conversation; an explicit Graph agent reaches its own steps. Automatic limit fallback and reset waiting remain the second PR, with mechanisms still undecided. This review makes no recovery or installed-acceptance claim.
