Jack Heart authorized complete document delivery. Selecting a document gives the agent its contents in the submitted turn. No additional retrieval action belongs in the workflow.

The mismatch this resolves

Before: preview showed the file body; execution supplied a path. A correct final marker could come from a file-read tool after omission.

Implemented on this branch: selection → document snapshot → submitted reference text → provider and immutable capture. Preview uses the same assembly.

Gate acceptance is pending. Installed behavior has not been verified. No new behavior is proposed by this review.

One interaction, through the model

lf --context --json --docs long.txt skill default 'Report the final marker without tools.'
lf -b -a codex --docs long.txt skill default 'Report the final marker without tools.'

gather_doc_targets reads a Document snapshot. format_task_prompt renders its complete escaped reference for both ordinary and native skills. preview_prompt shows the assembly; attributed_context records submitted bytes and their source.

Files own authored content; each invocation owns its snapshot; capture owns historical evidence. Preview and launch agree when their source files are unchanged. Editing a file later cannot rewrite an earlier capture.

Failure and recovery

An exact unreadable or nontext selection names the path and fails. Correct it and invoke again. Exclusions stay visible; external files never enter an unrelated repository matcher. Provider limits remain failures with attempted input preserved, without automatic document shortening.

lf -b connect ID --message 'Read the next document.' --docs next.txt

On a supported conversation, resume sends the new selection; old documents stay in native history. Re-selecting a changed file sends its new snapshot. ContextDelivery.submitted_docs retains only identities to suppress ambient duplicates. No document store or new lifecycle is needed.

Review questions, settled by the accepted contract

  1. Must an agent read selected files itself? No. Complete submitted references satisfy the accepted no-tools outcome. Existing usage docs describe this; skills need no retrieval instruction.
  2. Should old documents be replayed into each turn? No. Preserve native history and immutable captures; supply the current selection. Ambient-only context retains its refresh behavior.
  3. What proof remains? The specified gate checks must compare preview, provider input and capture, including resume. A marker obtained by a tool remains a counterexample. Infrastructure owns release, installation and installed verification.
