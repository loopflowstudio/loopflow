Recommendation: ship as built. The outcome this Task promises (every open Task runs again or names one command) now holds for the crash case; the fresh thread carries the original request and skill, so the agent's first reply already shows where it starts. Counterexample kept

thread_lost reads the home from the resuming process's CLAUDE_CONFIG_DIR/CODEX_HOME, which for the pass is the server's. A thread that ran under another home reads as gone. The fresh start is still right (Claude started by that server couldn't resume it either), but the pane's "is gone" is false: the file exists elsewhere. Before slice 6 this case failed five times and gave up.
