Failure, recovery & counterexamples checked

Invalid YAML on disk (counterexample)

No reconnect churn. A YAML syntax error does not end the stream: the server sends SubscriptionFrame(body: nil, unavailable: "Read …") and keeps watching the file. The backoff loop runs only when the stream itself ends or throws.

Manual Refresh or scope change during backoff

Instant, never waits on sleep. Clicking Refresh or changing checkout/Wave/target assigns a new observation = UUID(), canceling the sleeping .task(id:) and connecting immediately with fresh 1 s backoff.

Disconnect mid-edit / window closed

No hang, no leak. Every loop exit clears self.stream = nil, calls finishConfirmations(through: .max), and awaits stream.cancel() before sleeping. Closing Settings cancels the task and exits the loop cleanly.
