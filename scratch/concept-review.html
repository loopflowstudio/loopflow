Why it matters now

Its first three tabs are Brief, Diff and Files. "Files" names the pane and one tab of it, the remainder of "why does files show up three times".

The brief asks that nobody wonders "which Task they are viewing". The pane's name and the Task's name are the same slot.

Not decided here: no recorded decision picks a name, and the menu title is shared with tabs LOO-497 owns.

Two hide lists, different on purpose

Hidden by the worker for this change

hide: in the order file. A path or a folder. Carries a reason. Show per entry. Ends with the change.

Always hidden

diff_hidden. Text matched anywhere in a path, ignoring case. One toggle shows them all. Yours, per repository.

Neither writes into the other. Both stay in the count: "7 changes in 4 of 9 files".

When the worker's order exists

lf pr submit and lf pr land clear added scratch/ files in every repository, not only this one. The code Graph runs human-review before deliver, so the order is there the first time you read the Diff and gone once the PR is published: at verify, and whenever you reopen the Task later.
