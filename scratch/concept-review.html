As built

A Machine's ref holds its whole plan, so every record that arrives from the hub is owed to this Machine's own ref. A save sends by both carriers at once; what the hub's read brings in that same moment misses the push beside it. With a server the next minute sends it. With none the line reads Plan: Git origin, 3 unsent. naming a Task the mini made, until the next save or lf task sync. Offline from Git with a hub in reach, the count grows with everyone's work.

Not built: three ways, none chosen

a. Leave it: the count is true of the ref and settles itself.

b. A save sends to the hub, then pushes, under the one deadline. Nothing is left over; a hanging hub then leaves Git no time, so a save that Git could have carried stays unsent.

c. The line counts only records whose newest stamp is this Machine's and says nothing of the rest. Matches the word; hides the one case whole-plan refs exist for (a teammate who cannot push, carried by your ref).

Left as built for this work. It changes a count in a state that mends itself, and each fix trades it for something else a person would meet.
