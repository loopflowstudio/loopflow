Open product choice. Jack Heart proposed Desktop-only automatic presentation after seeing the original files open in Rex. The accepted contract still presents through every supported attached host. This headless review cannot accept the proposal; loop-or-next owns the next routing decision.

Proposed skill instruction:

Present the original docs only in an already attached Desktop Files view; otherwise report their paths and continue. Never launch a host to show them.

This changes automatic presentation in the workflow. It does not authorize removing explicit terminal file opening or building a universal rendered viewer. Both alternatives preserve the original files, drafts, saved corrections, existing Sessions, implementation loop and LOO-498 stack.

If accepted, change the workflow's presentation policy and its usage/skill wording. Keep explicit lf open --file, Desktop's existing files(path) action and current-viewer transport ownership. A failed or absent Desktop leaves paths available without launching another host. No new review record, file store or viewer service follows from this proposal.
