Action → concept → API

The user's action: build Loopflow.app any way the repo offers, then open it. The one concept: the app executable in a bundle, meaning the binary plus the frameworks it links.

install, dev, release, the launch benchmark and the third-party rebuild all call it. _embed_frameworks is private. executable_name is the only reader of CFBundleExecutable, and no builder rewrites that key.

The mismatch, closed

The incident happened because a builder could copy the binary without embedding its frameworks. Both steps are now one function, so a builder can no longer do one and skip the other.
