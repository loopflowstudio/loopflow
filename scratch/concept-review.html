Simulated Mitchell Hashimoto review

An inference applying his public engineering writing to this code. He did not participate in this review; the findings and recommendations are ours.

1. Finish the interaction people will feel

Keep the two commands. The concrete weakness is a permanent bind whose preview omits its actual directory outcome. Show the destination and timing before confirmation. This applies his emphasis on lived interaction in You Have to Feel It.

2. Keep observed state and intent distinct

cwd and requested_cwd earn their distinction. The transaction commits binding, primary selection and pending intent together; provider admission later confirms the move. A new move-job lifecycle would add machinery without improving this promise. This recommendation applies the incremental, demonstrable approach in Building Large Technical Projects.

3. Prove recovery, including what remains after an error

The failure fixtures assert retained state and successful retry, including after another Session becomes primary. That follows the testing priority described in Testing Error Recovery. Installation upgrade and the combined gate still need execution; inspection alone does not supply that proof.

4. Use the real path before declaring continuity

The cmux demo exposed hostname case normalization despite earlier test passes; the repaired owner now reports the right Cmd-T directory. Desktop creation while its composer contains an unsent draft remains unproven. Exercise that exact path rather than extending the CLI result to Desktop.

Contract retained and proposed guidance

Explicit adoption only. No --new, --primary, or task promote. Other conversations remain associated. Same-worktree subdirectories survive. Shared checkouts are not adopted. Done Tasks stay done. Permanent conflicting Task membership remains intact. No Graph starts implicitly.

Proposed agent guidance: report current and requested directory separately after binding. Preserve live input and native identity. Resume the same Session at its supported boundary and verify its directory before saying it moved.
