The mismatch

The CLI renamed task resume to task release so “resume” would mean one thing: get back to a conversation. Desktop kept the old words on the Task, a few inches from the Session pane’s own Resume button.

Task header        [Complete] [Resume] [Abandon…]     ← existing (held Task)
                   [Complete] [Release] [Abandon…]    ← proposed
Context menu       Defer Task / Resume Task             ← existing
                   Hold Task / Release Task             ← proposed
Session pane       [Resume]                             unchanged: that one is a conversation

Checked, unchanged

No CLI or Desktop caller uses session attach, connect, --takeover, --try, --if-free, --fresh or task pause/resume. resume and session new help describe the accepted behavior. Release notes keep their shipped wording.
