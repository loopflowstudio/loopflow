LOO-1061 · Concept review

Mac terminal appearance

Do the product’s concepts and the code’s concepts line up? This review covers the text people read in a Task shell or Session and the places they can change how it looks.

Regular text starts out thickened

The app bundles a regular face and separate bold and italic faces. The default Mac configuration also tells Ghostty to thicken all strokes. A person reading ordinary output sees that rendering choice even when the program chose regular text.

Remove the override. Spline Sans Mono keeps its glyph metrics and bold and italic faces. Lowering the strength still enables thickening, even at zero. A lighter face changes glyph shapes and fallback. The existing Ghostty option gives people who prefer thicker strokes a reversible choice.

Try it in a pane

Start with the proposed default and a test configuration with no weight setting. This is the walkthrough for the built change.

  1. Read the output

    Compare regular, bold and italic text in a Task shell and Session. Preview Dark, then Cancel. The palette changes and returns while the three text styles keep their weight and shape.

  2. Put the option in a theme file

    Import a valid color theme with font-thicken = true. The import lists the omission. Its colors preview in the pane while ordinary text keeps native strokes.

  3. Move it to Ghostty config

    Set font-thicken = true in the test Ghostty config and reopen Loopflow. Both panes use thicker strokes. Remove the line and reopen to recover native strokes with the chosen palette.

A color change that flips an explicit weight would falsify the shared baseline. If the baseline reads false and the same ordinary text still looks heavy, compare the real pane with the base build at the same size, display scale and palette. Inspect the selected face or renderer before claiming the default is fixed.
