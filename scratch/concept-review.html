The mismatch

Two readers show the same diff with different abilities. Changes has word emphasis, side by side, moves, cross-file next/previous and selection → Ask. Files' Diff mode is a plain text view with green and red line backgrounds. Changes' own file menu, "Open in Files", sends you to the weaker one. The design's forbidden outcomes already say "A second Diff renderer".

Now

Files · Diff  → TaskPatchView
              → TaskPatchTextView
              → TaskPatchLine, patchLines
Changes       → ReviewDiff stream

Proposed

Files · Diff  → ReviewDiff stream
                (one file, draft-aware)
Changes       → ReviewDiff stream

What must survive: diffing the unsaved draft as you type (the draft argument and 180 ms debounce in loadDiff). The stream gains it; nothing else about Files changes.
