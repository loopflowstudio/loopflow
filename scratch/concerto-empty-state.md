# Empty state should teach the model and offer a primary action

The empty state should both explain what waves are and provide an immediate way to start.

## Current

The empty state text suggests creating a wave but does not show a clear action. The sidebar can appear empty without explaining how it will look when populated.

## Problem

New or returning users cannot form the mental model or take a quick action. This slows exploration and makes the UI feel like setup.

## Build

- Add a primary "Create Wave" or "Quick Run" button in the empty state
- Show a structural preview of the sidebar sections
- Add a one-line explanation of what a wave does

## Done when

A user can understand the layout and start a wave in one visible click.
