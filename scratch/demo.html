2. Match the file to the displayed paths

context:
  docs: [README.md]
  exclude: [vendor, generated]
  diff: true
  budgets:
    scratch_tokens: 8000

The same block works in personal and repository preferences, skill frontmatter, and targeted Graph-step settings. Lists append; [] clears inherited entries. context.exclude filters supplied documents and changed-file contents. It does not restrict the agent’s own searches or Git commands.

Existing CLI flags keep their spelling: --docs, --diff and -c. Setters use the displayed paths:

lf set context.exclude '[docs/generated/**]'
lf set skills.design.context.docs '[docs/product.md]'

These setter examples change private project preferences when run; the demo wrapper is isolated from real preferences.
