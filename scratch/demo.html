Everything runs on a private Machine. demo-lf is the branch build with its own LF_HOME, so your real ~/.lf and Linear are never touched. Its agent is claude:haiku.

Steps

1. Set up the shortcut

DL=$HOME/.local/share/loopflow/demos/task-session-at-checkout-20261107-runtime/bin/demo-lf
cd $HOME/.local/share/loopflow/demos/task-session-at-checkout-20261107/repo

2. Start a Task the way you did with ad319b

$DL task create --title "Add a closing line to the README" --notes "Demo"
$DL task run <ID it printed>
$DL session list
Expect: task run returns once the Graph has started. Within a few seconds session list shows the Task's conversation as detached, before you have opened anything.

3. Resume it from the worktree

cd "$($DL task status <ID> | sed -n 's/^  worktree: //p')"
time $DL resume
Expect: no "Nothing to resume here". Claude is already running, with its reading turn on screen, about a second after you press return. Press Ctrl+] to detach when done.

4. Leave a comment, then come back

$DL comment <ID> 'Use the word "Goodbye" in the closing line'
$DL resume
Expect: the conversation receives a Task update containing New comment from jack: Use the word "Goodbye"… and mentions it briefly.

5. Read the launch log

tail -8 $HOME/.local/share/loopflow/demos/task-session-at-checkout-20261107/home/logs/launch-timing.jsonl
Expect: background_start, then prompt_begin, prompt_end, provider_exec_begin, then task_sync_begin and task_sync_end. Each line has load1.

6. Leave it alone for three minutes while the Graph runs

$DL session list
Expect: the conversation is still detached, not ended, because its Task's Graph is running. A conversation for a Task with no running Graph ends about two minutes after it goes quiet.

Known gaps

Fixed since this page was written: lf task move now waits up to 20 s for a conversation that is still starting, and the colliding test fixture acts only for its own launch. Clippy is clean. Nothing automated yet exercises checkout starting a conversation; see scratch/task-session-at-checkout.md.
