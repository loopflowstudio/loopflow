Loopflow for Mac, three further directions

Each page is the same window: the Task sidebar, LOO-515 selected, its place in the feature workflow, its conversation in a terminal, and New Task below. Each direction changes what the window is organised around, not only how it is dressed.

The earlier directions (Score, Terminal-native, Instrument panel)

Ledger

Every list has two columns: theirs and yours. What you owe is the only thing in the right column, and the sidebar ends in a balance. A repeated step is a ditto mark; a loop is a bracket in the margin.

Carries: the empty right column as the picture of a quiet day; “Owed by you: 2” as the one number the app shows. Risk: the ruled paper is a costume if the two columns are not doing real work on every screen, and three columns make the sidebar wide.

Stations

A Task is a line and a step is a station, at the same position in every row, so the sidebar reads down as well as across. A step that is yours is a ring; a Task waiting there fills it in wine. A loop is a return track, drawn darker once it has been taken.

Carries: shared station positions (you see three Tasks stacked at build without reading); “at your stop” as the phrase for waiting. Risk: it assumes every Task runs the same workflow; a second Graph needs a second set of columns.

Tide

Each Task is a water level through the day. Agents make it climb; a flat wine line is time it spent waiting on you; a loop shows as a wave. The sidebar shares one clock, and New Task shows the shape before it starts.

Carries: waiting drawn as length, so 52 minutes looks different from 15; a loop that needs no symbol. Risk: it is a chart, and a chart per row is a lot of ink for a Task that has only just started.
