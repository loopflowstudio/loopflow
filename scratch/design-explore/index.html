Three design languages, pushed as far as they go

Each page shows the same four things with the same Tasks: the homepage first screen, the Task row, the workflow line and New Task. They are meant to be too much. The point is to find which ideas survive being pulled back.

Three further directions, shown on the Mac app: Ledger, Stations, Tide.

Score

Tasks are parts in a score and steps are bars. A step that waits for you is a fermata; a loop is a repeat sign with its count; a landed Task ends on a final barline. One engraving face, black ink, and red only for what is yours.

Carries: a single mark for "yours" that needs no legend once learned; a Task list that reads as one picture. Risk: costume, and notation nobody asked to learn.

Terminal-native

One monospace, one size, on the character grid, in the reader's own terminal colors. The Task row is the line lf task status prints, so the Mac sidebar, the phone and the shell show the same thing. The workflow is box-drawing text that pastes into a pull request.

Carries: one row design on every surface; theme for free. Risk: it looks like other developer tools unless the spacing is exceptional. Use the theme switch at the top.

Instrument panel

A rack with one strip per Task: a lamp, a written label, a five-segment ladder. Red means you and nothing else is red. A step that is yours is drawn as an open switch in the signal chain.

Carries: the loudest possible "needs you", and the quietest everything else. Risk: a control room, and dark-with-one-accent is a common generated look.

Pulling back toward Wine and ink

Wine and ink is what Desktop already does well: burgundy as the one owned color, warm charcoal terminals, a humanist sans, almost no shadow. These are the ideas from each direction that could land there without the costume.
