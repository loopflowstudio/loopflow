04 / Act on the work

These are Work actions through existing shared APIs. The pane controls below support them; screen text or terminal input never substitutes for a Task’s legal actions or state.

Find or open the repository window, select the Task, reuse the requested Session and arrange its diff beside it. Create a Session only when requested.

Return the window, pane and Session identities, plus whether each view is opening, usable or failed. The agent verifies the result, reads output, renames the Session and adjusts the layout through the CLI.

Unique shortcuts stay: lf ps resolves to lf monitor ps; lf open is ambiguous between Desktop and PR opening. Use lf desktop open.

Flags by purpose

General: --explain, --json, --verbose, --help. Explain reads how this invocation resolves without performing its effects.

Selection: --repo, --machine; --task, --wave, --wt where meaningful.

Agent input: --context previews without launching; --docs, --clipboard, --diff choose input.

Agent and mode: --agent, account selectors, isolation, interactive/batch.

Execution settings: --chrome, --yolo. Remove --max-turns and --no-loopflow; keep --steers-after for bounded continuation context.
