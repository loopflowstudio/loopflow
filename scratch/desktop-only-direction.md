# LOO-728 — accepted Desktop-only automatic presentation

Jack Heart selected “desktop only” in the primary conversation on November 4,
2026, resolving the earlier automatic-presentation choice. This decision
supersedes descriptions of that proposal as unresolved or unaccepted.

- Write and reread the actual saved docs on every Machine.
- Automatically present them only in an already attached Loopflow Desktop Files
  view, retaining rendered Markdown/HTML, drafts and attention behavior.
- Elsewhere report the original documentation paths and continue. Do not
  automatically launch terminal editors, browsers, hosts or conversations.
- Keep the existing no-extra-approval-stop workflow and return edges to implement.
- This decision changes automatic presentation. It does not remove explicitly
  requested `lf open --file`, add a universal viewer, or replace Files/transport.

The live implementation run owns the corresponding code, skill, documentation
and check changes, and reconciliation of its canonical design. Terminal
auto-opening is no longer an acceptance requirement. Existing shipping approval,
source preservation and the LOO-498 parent boundary remain in effect.
