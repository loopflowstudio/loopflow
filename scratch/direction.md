## Concept review (2026-10-29, headless)
The user-facing model matches the Task's accepted direction: one verdict per checkout (`keep`/`remove` + reason), a default that removes what evidence shows is finished, and `--all` that removes everything except unfinished Tasks' checkouts, persistent checkouts, the default branch, the current checkout and paths a running process holds — saving unpushed work first. No concept to merge or rename; no code change from this review.
- Idle-conversation rule (below) is settled as a follow-up, not this PR: the Task's accepted direction says `--all` skips "any live process's cwd", which this PR does. Telling an idle agent conversation from live work needs Session availability per holding process, a separate change.
- Counterexample to carry into that follow-up: `InUse` counts any open file from any process (`lsof`), so a Desktop or watcher process with a cwd in every checkout would keep all of them. The 2026-10-29 cleanup excluded `lf desktop plan --watch` watchers by hand.
- Recovery has two namespaces today: prune's `refs/lf/pruned/<branch>/<commit>` and the hand cleanup's `refs/prune-backup/<dir>`. Only the first is product behavior.
