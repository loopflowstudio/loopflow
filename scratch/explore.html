It scales across your machines and your subscriptions.

      
Private, secure remote jobs and telemetry made easy through ssh, and multi-subscription balancing that moves to the next login when one runs out. Rent a machine for one Task and give it back after.

Together, with your team.

      
Each task has one owner, one working copy and one pull request, so your agents and a friend’s agents can work in the same project without taking the same task or writing over each other.

      
The plan is shared: your tasks live on a shared ref in your project’s GitHub repository, or in Linear. Comment on someone’s task, and their agents read it before their next step. Your conversations stay on your computer; only the plan travels.

    


    

      
Yours, even if we disappear.

      
MIT, and nothing hosted. If Loopflow stopped tomorrow, your Tasks, conversations and Graphs would still be in your repo and on your machine.

Shipping code is no longer the hard part. Scaling your attention and vision is.

      
Coding agents can do amazing things for you, but they ask amazing focus of you. Loopflow helps you do that by arranging your agent sessions around clear work boundaries: long-lived areas of responsibility and objectives and concrete outcomes.

    


    

      

        

          
Your process, as code.

          
A Task’s workflow is a Graph: a YAML list of Skills, and a Skill is a Markdown file, both in your repository and reviewed like code. Each step can name its own agent. A step marked interactive: is where a person takes part.

        

        


<!-- .lf/skills/audit.md -->
Audit auth changes on this branch. Fix missing
validation and untested paths.

# .lf/graphs/ship-api.yaml
- interactive: design
- implement
- audit
- gate

        

      

    


    

      

        

          
Areas of work with their own defaults.

          
A Wave is an area of work with its own goal, memory and plan, and its own setup for every Task in it: the Graph, the agent, the machine and the login that pays.

        

        


# .lf/wave/infrastructure/config.yaml
graph: auto     # request to merged PR, without you
agent: claude:opus
$ lf --wave infrastructure set machine mini
$ lf wave status infrastructure

A workflow
The Graph it runs, each step in the Task’s own worktree and branch.

        
Its own pull request
Branch and tracker issue, kept together, with every run and what it cost.
