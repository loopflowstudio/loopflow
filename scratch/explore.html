Settings Pane Redesign

LOO-1066 · Make Loopflow for Mac’s Settings window feel like a standard Apple Settings pane, closer to Rex.

Decision needed

Choose how far Settings should move beyond a sidebar reskin: keep the existing 5 tabs inside native Apple chrome (Vision A), promote Loopflow’s lf config catalog keys into typed native controls grouped by domain like Rex (Vision B), or turn Settings into a live scope-and-override control plane with direct control search (Vision C). Existing

Five uneven tabs in LoopflowApp.swift: a 1-checkbox Editing pane, a 700×560 Theme Chooser with Cancel/Apply, and a raw single-key YAML editor for all 47 config keys. Click tabs to compare.

Configuration

Vision A · Native Apple Sidebar Shell

Proposed

Rehouse what Loopflow already has inside a standard macOS NavigationSplitView sidebar and grouped Form rows, folding Editing into General and picking Projects from Portfolio instead of typing file paths.

Settings

General

Demo

Press ⌘,. Click General, Appearance, Mobile, Keyboard Shortcuts, and Configuration in the left sidebar. Toggle Autosave, switch themes in grouped cards, and pick a repository from Portfolio inside Configuration.

Cost

Smallest. SwiftUI only (4–6 files in swift/LoopflowMac/). Zero Rust changes, zero wire DTO changes, existing config.* calls untouched.

Trade-off

Clean Apple look fast, but everyday settings (agent, yolo, wave.graph, land) still live behind a single-key YAML editor in the Configuration pane.

Vision B · Typed Native Preferences (Rex-style)

Proposed

Promote Loopflow’s lf config catalog into real macOS controls grouped into Apple Settings panes (General, Appearance, Agents, Context, Git & Release, Machines, Mobile, Shortcuts), with a clean Scope picker and per-row Reset.

Settings

Agents

Scope

Demo

Press ⌘,, open Agents, flip Run agents without asking, change Codex tier to priority, then switch Scope to Project · loopflow (Shared) to see inherited vs overridden rows with one-click Reset.

Cost

Medium. SwiftUI sidebar + typed form rows (bool, enum, string, list, fallback YAML), plus 1 Rust read (wiring config.settings or adding config.layer) so panes load all keys in one round-trip instead of 47.

Trade-off

Configuration stops feeling like a developer tool. Complex map keys (pools, ondemands, diff_groups) still expand into inline YAML disclosures at the bottom of their domain pane.

Vision C · Apple Settings + Live Override Lens

Radical success

Everything in Vision B, plus control-level Spotlight search (try typing yolo, dark, or tailscale), clickable provenance pills that open an interactive precedence ladder with one-click Promote/Reset and live YAML diff, live sidebar health dots, and instant-apply Theme switching with Undo.

Settings

Agents

Demo

Type yolo in the sidebar search and toggle it right from results. Click the blue Personal repo pill on Default agent to inspect the 4-layer cascade, see the exact YAML diff, and promote or reset with one click. Switch a theme card and press Undo.

Cost

Largest. Everything in Vision B plus a live search index across app + catalog controls, an interactive precedence popover with layer-move mutations in Rust, live status probes for Mobile/Machines, and an Undo stack for Appearance.

Trade-off

Turns Settings into the fastest way to understand and edit Loopflow’s layered config. Main risk is visual noise if scope/override badges shout when a person just wants to change a theme; they must stay quiet on Global and expand only on click.

  1. 1. How far should Configuration go in this redesign?

    • 1a Vision A: Native Apple sidebar + grouped forms around the 5 existing panes (SwiftUI only, Configuration stays a cleaner key/YAML editor).
    • 1b Vision B: Split lf config catalog into typed native controls across domain panes (General, Appearance, Agents, Context, Git & Release, Machines, Mobile, Shortcuts) with a Scope picker.
    • 1c Vision C: Vision B plus control-level search, interactive precedence ladder with Promote/Reset, and live status dots.

  2. 2. Visual skin inside the Settings window (try the top-right toggle)

    • 2a Native Apple chrome: macOS System Settings colors, vibrancy sidebar, system accent, rounded-square colored SF Symbol badges (closest to Rex and System Settings).
    • 2b Loopflow Palette: native macOS sidebar and grouped form geometry, rendered with the active Loopflow theme palette, burgundy accent, and monochrome SF Symbols.

  3. 3. Apply model for Appearance and Configuration

    • 3a Instant apply on click/toggle (standard Apple Settings + Rex), with Undo / Reset to default instead of a Cancel/Apply footer.
    • 3b Keep explicit Cancel / Apply for Theme editing and raw YAML edits; instant apply for simple toggles and pickers.

  4. 4. Sidebar structure

    • 4a Flat sidebar (5–7 items, no section dividers): General, Appearance, Agents, Context, Machines, Mobile, Shortcuts.
    • 4b Grouped sidebar (App · Workflow · Infrastructure dividers, as in Vision B and C).
