Refining V4: one vocabulary, tied to the step, zero jump

What changed from Round 3's V4: Collapsed four overlapping words (Moving / Run / Start / Start from…) into one plain Graph vocabulary, fixed every slot width so rapid-clicking ⏸ ↔ ▶ moves 0px, and stripped the redundant sentence off the left.

Before (too many words) Moving · Ship Review · Run · Start · Start from… · Unpause
Now (one verb + step name) Running · build · Paused at build · Waiting · ship-review · Run / Pause + direct step chips inside the pill
State:

V4a · Pill Names the Stage (Running · build / Paused at build) + Locked Icons

Strict 0px jump

Fixed-width Status Pill (150px) speaks in plain Graph language. One single toggle icon beside it flips ⏸ ↔ ▶ in place (never spawns a second button), followed by fixed Auto [●] and fixed ✓ (lights burgundy on merge).

Click the pill to check the menu

One verb (Run / Pause), direct step chips (plan build ship-review deliver verify) instead of a nested "Start from…" submenu, then Unassign, Complete, Abandon….

Trade-off

Literally 0px movement across every state and every click. Because ✓ stays icon-sized even when merged (just turns burgundy), nothing ever shifts — though a new user learns ✓ = Complete from its tooltip or the pill menu.

V4b · Pill Names the Substep (Running · implement / Paused at implement)

Zero repetition with Graph

Left Graph highlights the top-level stage (build); right pill names the exact inner step (Running · implement, Paused at implement, Waiting · ship-review, Merged · verify) — so left and right complement each other instead of both saying build.

Why this is neat

You see where in the arc on the left (build highlighted with a live dot) and what's actually executing in the pill (Running · implement / Paused at implement). Zero word duplication, and Complete expands cleanly to burgundy ✓ Complete only when PR is merged (and the ▶/⏸ icon drops away, keeping total width steady).

Trade-off

For single-step stages like ship-review or verify, the substep and stage have the same name (Waiting · ship-review), which still reads naturally.

V4c · Pill IS the Toggle + Step Selector ([⏸ | Running · implement ▾]) + Auto + ✓

Even cleaner V4

Merges V4's standalone ⏸/▶ icon straight into the left edge of the pill as a soft split capsule — click ⏸ to pause in place, click Running · implement ▾ to jump steps or change state. Right edge shrinks to just Auto [●] · ✓ · ···.

Why this is neat

Removes the loose floating icon between the pill and the Auto switch: the pause/play icon is visually bound directly to the Running · implement / Paused at implement label it controls, with 0px jump on every click.

Trade-off

The split pill needs a crisp hover split so it's obvious the icon on the left pauses/resumes while the text + chevron opens the menu.
