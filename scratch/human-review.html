1. What changes

An interactive lf -a claude … started from an agent's shell used to show this and save nothing:

⚠ Transcript saving is off — inherited CLAUDE_CODE_CHILD_SESSION marker

…and lf resume later failed with No conversation found with session ID: 1daa55fc-…. Now the chat saves its transcript and resumes. A nested Codex no longer takes its caller's sandbox. CLAUDE_CONFIG_DIR, CODEX_HOME, tokens and API keys still pass through.

5. Choices made for you

  • One list for lf's and providers' markers, renamed from EXECUTION_IDENTITY_ENV. Passed over: a separate PROVIDER_SESSION_ENV.
  • Remove markers rather than set CLAUDE_CODE_FORCE_SESSION_PERSISTENCE; removal also cuts the messaging socket and notes dir.
  • NO_COLOR, PAGER, LC_ALL etc. from Codex shells pass through. Cost: colorless, unpaged claude when lf runs from Codex.
  • AI_AGENT removed although a person could set it.
  • start_held left unchanged, against the original plan table.
