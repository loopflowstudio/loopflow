PR #1990, head 3c99944f26, 2026-11-19. Code last changed at edf0aeef5f; QA ran against that code, and the one commit since touches only scratch/.

Nobody was at this review. The run went on to gate because every "Done when" line in the plan was seen to hold. The six questions at the bottom are unanswered, and each one says what the branch does meanwhile.

1. What changes

  • Running tests: cargo test -p loopflow --test <name> no longer fails on its first run after lf is linked. The test process stopped rebuilding lf over the path its own Machine server runs from.
  • Using lf: when a running server's lf has been replaced and it needs a new terminal holder, the command fails in about two seconds and says so. Before: 20 seconds, then a socket path.
  • Two traps are closed for later tests: an execution unit test can't call journal::with_process, and the New Task Swift tests don't watch warm primary openings.
  • Of the four named tests, two were already fixed on main (#1972, #1982). This branch adds nothing for the service-tier test.

Biggest mismatch: a build is started by path. The server knows its build by hash and spawns current_exe(), trusting the path. This branch makes the split fail fast and stops integration tests causing it; the split is still possible. To remove it: Place carries the executable the holder runs, and the server links or copies its own executable there at start and always spawns that file. Cost: one binary per live build under the holder state, a copy when a hard link crosses volumes, cleanup when the holder exits. Not built (question 1).

The whole product change is this, in rust/loopflow-execution/src/terminal_holder/client.rs:

pub fn ensure(place: &Place, build: &str) -> Result<Self> {
    if let Ok(client) = Self::connect(place) {
        return Ok(client);
    }
    let executable = holder_executable()?;
    // The executable was replaced since this process started: its holder
    // binds another build's place, and nobody will bind this one.
    if let Some(started) = spawn(&executable)?.filter(|started| started != build) {
        // Twelve digits, as the socket and state directory are named.
        let short = |build: &str| build.get(..12).unwrap_or(build).to_owned();
        bail!(
            "The executable at {} is now build {}; this server is build {} and has been \
             replaced since it started. Run `lf install server` to restart it",
            executable.display(), short(&started), short(build)
        );
    }

And the test fix, in rust/loopflow/tests/support/mod.rs:

if let (Some(built), None) = (
    option_env!("CARGO_BIN_EXE_lf"),
    std::env::var_os("LOOPFLOW_TEST_LF"),
) {
    std::env::set_var("LOOPFLOW_TEST_LF", built);
}
