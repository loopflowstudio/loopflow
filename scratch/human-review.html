1. What changes for people

Without Linear or Asana, the plan travels with the repository. Each Machine pushes its whole plan to refs/loopflow/plan/<machine id> as part of the save, and its server reads the others’ once a minute. Clone the repository on a second Machine, or as a teammate, and the plan is there. No account, no hub, no --bind. A hub (lf machine hub mini) makes it seconds instead of a minute, and is no longer where the plan lives. Two edits to one field: the later one wins everywhere, with nothing ever lost or conflicted. Two claims made apart: the first one holds.

Biggest mismatch: “unsent” counts the mirror, not your changes. With a hub and no server, a save’s Git push runs beside the hub read, so what the hub just brought reads Plan: Git origin, 3 unsent. naming a Task the mini made, until the next save or sync. It mends itself. Fixing it means either hub-then-Git in a save (a hanging hub then eats Git’s five seconds) or counting only this Machine’s own changes (which hides the teammate-who-can’t-push case whole-plan refs exist for).
