scratch/human-review.html · branch jack-heart/43bf9b-remove-chapters-krs at 6c7374b3e4 · PR #1997, stacked on LOO-938 (#1983) · 179 files, +2,409 / −14,500. Written headless; nobody has reacted to it yet.

1. What changes for people

  • lf wave create makes a Wave and nothing else: no Project, no tracker write.
  • A Task created in or moved into a Wave joins the Wave's newest started Project, else its newest open one, else a new started Project named for the Wave. If the Wave has more than one open Project, the command says which one it joined.
  • Gone: the "current" Project, activation, rollover, KRs, metric targets, live metrics, the Project run journal, and lf wave update-project, edit-project and plan bind. Projects themselves stay: they start, end, show status and sync with Linear or Asana.
