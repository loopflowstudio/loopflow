Jack Heart authorized autonomous profiling and optimization on October 4, 2026.
The LOO-304 brief owns acceptance; this plan does not waive rendered evidence.

## Budgets fixed before candidate evaluation

Cold start ≤1000 ms, first frame ≤400 ms; Wave/Task and retained Session
interaction ≤100 ms; new PTY ≤500 ms; key-to-glyph one frame; CLI reads
≤300 ms off main actor; growth <32 MiB over four navigation rounds; idle
hitches ≤5 ms/s and no observed hangs. At least 20 successful observations
per comparable scenario for p95; report failures/timeouts and missing endpoints.
No budget revision is selected. Projection-only and query timing are supporting
evidence, not paint or interaction latency.

## Baseline, October 4 (installed 0.12.32, live Home, read-only)

Host load 85–107 on 16 CPUs; 325 Tasks, 119,112 Execs, 37 listed Sessions.
All timings are inflated by that load; no failures or timeouts.

| Read (cadence per window) | n | p50 | p95 |
| --- | --- | --- | --- |
| `session list --json --page --limit 100` (2 s) | 20 | 16,903 ms | 24,599 ms |
| `roadmap --json` (15 s) | 8 | 30,617 ms | 37,204 ms |
| `wave list --all --current --json` (15 s) | 8 | 4,102 ms | 5,239 ms |

`sample` of live reads: the Session page spent all 2,571 samples launching
`git rev-parse --show-toplevel` for every recorded checkout. Roadmap spent 64%

the installed CLI once per Task, 3% in `git rev-parse --git-common-dir`.

## Changes

Delete — do not maintain: Podium `ps` polling, its process state, signal enum
and exclusive fixtures/tests (done); per-Task Session scans in
WorkspaceProjection (done); competing Session enumerations (done: joined).
Preserved: input order, multi-Task membership, explicit scopes, unmatched
records, partial-page retention, generation fencing, all history and authority.

- `git::worktree_root` reads the filesystem; no process per checkout.
- Completion/recovery checks read only unfinished Execs through the
  `execs_unfinished` partial index (draft `index_unfinished_execs`). `task_work`
  still returns complete history for Task status and Desktop.
- The installed CLI digest is verified once per process while path, size and
  modification time are unchanged.

Same snapshot, same host, 325 Tasks: Exec membership per Task p50 54.93 ms →
0.69 ms, p95 146.15 → 0.88 ms, total 21.5 s → 0.27 s; unfinished sets identical
for every Task. Projection receipt from the earlier pass was not retained;
`LF_WORKSPACE_PERF_OUTPUT` regenerates it.

## Remaining

- End-to-end CLI candidate timing needs a release build against the snapshot
  with LOO-371's isolated runner; host load and 25 GiB free disk prevented one
  here. Expected remaining roadmap cost: `git status` and `--git-common-dir`
  per Task with a checkout.
- Each window still starts one `session list` every 2 s and `roadmap --all`
  plus `wave list` every 15 s. A change signal would remove idle reads; none is
  selected.
- `RegistryQuery.processActivity` and `ActivitySnapshot` have only test callers.
- Native repeated journeys and the hour-long idle/navigation/typing soak (CPU,
  RSS, hitches, focus transitions, retained pane/draft proofs) belong to a
  capable display host after LOO-371's runner settles. Swift suites were not run
  locally; gate/CI owns them.
