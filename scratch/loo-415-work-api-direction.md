# Accepted LOO-415 direction relevant to lifecycle

Full source: [archive](evidence/loo-415-work-api-direction-stack.txt).
Jack Heart requires native Claude UI on explicit resume and permits a necessary
provider restart for that explicit transition, preserving Session/native history
without replay. Prefer existing native attachment. Viewer/creator loss never
selects this transition. Attach-only restoration must remain attach-only.
Lifetime follows the resolved persistent Session, regardless of whether a command
spells Task/Wave. Foreground viewing and immediate-return policy are separate.
The owner preserves structured Runs until an explicit native transition; no custom
replacement UI or universal native-PTY conversion is selected.
