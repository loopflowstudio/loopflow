## Public contract

```sh
lf                                 # ordinary new conversation; existing behavior
lf connect                         # this scope's ongoing conversation
lf resume                          # exact alias for connect
lf --repo loopflow connect          # repository primary, even from a Task checkout
lf connect --wave infrastructure    # Wave primary
lf connect --task loo-499           # Task primary; case-insensitive ticket alias
lf connect SESSION                 # exact Session and its retained checkout
lf connect --wave infrastructure --fresh
lf connect --task loo-499 --prepare --json
```

`connect` is the documented verb; `resume` is a supported alias, including under
`session`. Scope selection reuses its primary or creates one if absent. Exact-ID
selection never changes the primary pointer. Do not use recency to select across
scopes. Root `open` already opens Desktop and is outside this rename.

| Invocation location | Bare connect/resume selection |
| --- | --- |
| Canonical main checkout | Repository primary |
| Repository's recorded persistent checkout | Repository primary |
| Task checkout | Task primary |
| Wave's recorded persistent checkout | Wave primary |
| Unassociated linked worktree | Explain the missing target; admit nothing |

Nested directories and aliases resolve through physical checkout association.
Main means the canonical Git checkout, not a branch named `main`. Explicit
Session/Work selectors override ambient context; explicit repository selection
without Work means repository scope. Conflicting explicit targets explain the
conflict before admission. Opening a scope uses its retained checkout, not the
incidental directory from which the command was invoked.

An unassociated-worktree error should offer existing paths:

```text
This worktree has no associated work conversation.
  lf                         Start a new conversation in this worktree
  lf --repo loopflow connect  Open the repository's ongoing conversation
  lf connect SESSION         Continue a particular conversation
```

Generate the repository example from the selected repository. Finding one ordinary
Session in that worktree does not establish a primary. Add no `--here` flag,
checkout-primary table, or new launch verb. Ordinary `lf` already stays in an
existing linked worktree; its main-checkout author-worktree placement stays intact.

## Fresh, preparation and instructions

`--fresh` creates/selects a new primary in the same scope and checkout, preserving
the predecessor's history, name and live client. It applies to scopes, not arbitrary
native IDs. Preserve explicit Task-primary selection on the surviving operation
(e.g. `connect --task ISSUE --choose SESSION`), validating membership through the
existing owner. Fresh and choose are different, mutually exclusive intents.

Selected routine retry policy: each explicit scope-only `--fresh` is a new request.
After an uncertain reply, ordinary connect recovers the current primary. Internal
provider-launch retries retain the already admitted Session; never mint another
Session because its provider failed to launch. Preserve predecessor/successor
identity internally where the existing replacement operation uses it. Do not add
public retry tokens or a second compatibility command.

Preparation can admit a Session and prepare its checkout, but launches no provider
and takes over no client, even with other launch flags supplied. JSON changes only
format. Explanation resolves the same intent without admission or other effects.

First creation uses the existing scope conversation skill and its operating
instructions. The earlier proposal to make primary conversations quiet is rejected.
An agent running those instructions may inspect and advance authorized work under
that skill; the transport itself does not run a Flow, rotate a Project, settle a
review, or replace active work. Preserve review/launch authority and live Flow
exclusion. Direct conversation-skill invocation supplies instructions/context,
not an implicit primary claim; missing required Work explains the canonical open
command. Root Work selectors on ordinary skills/Flows select context and placement,
without implying primary-conversation reuse.
