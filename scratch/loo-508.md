and autonomous delivery in LOO-508, waiving routine design, demo and merge approval.

Keep native editing and rendering exclusive while retaining Loopflow failures.
The retained transport gives the execution and its provider the same PTY;
`init_tracing` writes stderr, so relay, capture, planning and title-refresh
warnings can enter the native screen. Direct parent prints and inherited helper
output have the same collision. Startup already joins its renderer before spawn;
title OSC writes happen before spawn; later cmux updates use a separate channel.
OpenCode's existing provider stderr log must remain intact.

Use a scoped Unix descriptor handoff at native spawn and terminal attachment:
save stdout/stderr, route parent output to a private per-Process log, explicitly
give the native child its original descriptors, and restore on scope exit.
Transport delivery uses its saved descriptors. Announce the log before rendering
and report new diagnostics afterward. Failed log setup must fail before spawn;
ordinary CLI errors remain visible. No schema, history, account or provider
protocol changes.
