## Build/cache contract

Each worktree keeps its own mutable Cargo target. Ordinary Cargo builds work
without sccache; failed cache service falls back to direct compilation with
`RUSTC_WRAPPER=`. Do not share targets, clean production targets for a cache hit,
run separate servers against one local cache, or restart a shared daemon from a
rustc wrapper.

Installed sccache 0.19.0 missed identical libraries across roots. The verified
experimental binary is upstream
`ca81ec2a2566efc623692741440d99c710268841`, containing Rust basedir normalization
and verbatim environment dependencies. Each absolute root must be listed before
its daemon starts; their parent alone is insufficient. Keep runtime path inputs
`CARGO_MANIFEST_DIR`, `CARGO_MANIFEST_PATH` and `LOOPFLOW_BUILD_SOURCE_ROOT`
verbatim. Runtime checkout identity must remain correct.

Root inventory comes from `git worktree list --porcelain -z` plus the current
canonical root, preserving spaces and newlines. `scripts/dev-lf` invokes
`scripts/build_cache.py` before Cargo. Under a file lock it atomically refreshes
`XDG_CACHE_HOME/loopflow/sccache.json` (default `~/.cache`), retaining other
repositories and the Machine's default cache settings. The build selects that
file and verbatim identity dependencies; no new scheduler, service or restart
RPC exists. The existing daemon keeps its configuration until natural idle
shutdown. Ordinary Cargo does not refresh the inventory; explicit `SCCACHE_CONF`
and isolated builds remain caller-owned. The Machine's Cargo configuration and
wrapper are untouched. LOO-908 remains historical, not an integration prerequisite.

A cross-root hit retains A's absolute source/debug/generated-source paths in B's
rlib; the November 14 model and definition-content probes observed this despite
correct runtime identity. November 15 direction removes that as an extraction
stop. `scripts/dev-lf --isolated-build <lf args>` uses `target/isolated`, disables
both rustc wrappers and sccache, and leaves normal targets/cache intact. Normal
builds honor CARGO_TARGET_DIR and run its executable. No source remap or retention
service is selected. Binaries/tests still compile/link even on library hits.

build normally, and retrieve unchanged execution code. Running or resuming the
same Task from a terminal or Desktop reaches the same typed operation, saved
receipt, cursor and native conversation. A failed reply stays inspectable
without replaying the operation. No new command, Work record, dispatcher,
callback framework or execution approval.

**Model.** The engine stays the shared operation API, domain operations its
implementation, CLI/server dispatch the adapters. Name the lower crate for the
execution responsibility it actually contains; membership follows the production
closure and semantic co-change, not directory names. Do not move all of
`engine`, `ops`, `lf` or `util.rs` as directories. Provider acquisition stays
above storage. Keep application build identity out of reusable library bytes
except where runtime identity requires it. Delete each old implementation as it
moves; no forwarding layer.
