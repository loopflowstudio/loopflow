## Surviving design

Generated-output lifetime is independent of Task completion and source disposal.
Discovery follows Git ignore decisions and registered worktrees, including those
under ignored containers. Batched ignore queries avoid tracked-content filters.
Unregistered repositories hidden in ignored data trees remain a coverage limit.
SwiftPM package source is separate from architecture output; Cargo profiles can
be reclaimed separately. Only measured eligible candidates reach fresh checks.

One shared recovery lock, 30-minute run budget, bounded inspection and nonzero
partial-failure receipts make unattended failures visible. Installation copies
five files into a versioned machine directory, uses a clean environment and the
hourly :17 calendar job, and restores prior configuration/job on bootstrap failure.
The schedule never depends on a Task checkout. Native manual worktree pruning
retains its existing owner and tests.

Private usage history is bounded to 168 samples / 4 MiB / 256 roots and two minutes
per observation. Least recently attempted roots go first; growth compares the last
known measurement and its timestamp. Unknown measurements stay null. Retention and
content-type labels are independent; overlapping roots and APFS allocation cannot
be summed as exclusive physical use.

Native caps apply even with abundant space: uv 8 GiB per cache, sccache 10 GiB LRU,
Docker engine build cache 8 GiB. Native locks, recent/in-use records and reservations
can defer those limits. Registry-backed Docker images need 24h age and no container
reference; volumes, containers, unpublished images and remote/custom builders stay.

Package exclusion: `pyproject.toml` disables packaging; package CI archives only
`lf`; app bundling copies only `lf`; Swift resources name only Swift folders.
No product path enables this utility.
