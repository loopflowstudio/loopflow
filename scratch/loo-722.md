## What exists

The stable `scripts/disk-cleanup.sh` entry point launches a stdlib Python runner.
It shares verification recovery's nonblocking flock and resource-policy 64/32 GiB
thresholds. Generated-output retention falls from four hours to one hour below
64 GiB and fifteen minutes below 32 GiB; recovery restores normal retention.
Ignored, untracked roots anywhere below the source directory are measured and
sorted largest first, using the nearest owning checkout for Git checks. Discovery
skips symlinks, Git metadata and generated roots, with a 30-second/100,000-entry
bound and a visible partial failure. Cargo debug/release profiles can be reclaimed
separately when the whole target is retained. Global Xcode DerivedData contributes
project Build/Index.noindex directories and whole ModuleCache.noindex,
SDKStatCaches.noindex and CompilationCache.noindex directories; adjacent package
source survives repeated cycles even without Git metadata. Embedded Git checkouts
retain a candidate.

Open output and builders inside a checkout retain output; idle shell cwd alone
does not. Tracked content, symlink roots/ancestors, recent output, account history,
SQLite state and the newest regular backup per database remain protected.
Inspection runs again before removal. Direct builds newly racing that inspection
remain unsupported, as in the existing resource-recovery contract.

Candidate inspection has a 30-second limit, children at most two minutes, and
work a 30-minute budget. Timed-out child groups are killed and reaped; locks
release on death. Public `~/.local/bin/lf` owns native pruning with inherited LF
attribution stripped. Generated-output cleanup precedes native maintenance.
The receipt records candidate decisions, removed allocation, free-space delta,
shortfall and failures. Failed removals get no allocation credit. Log failures
allow independent reclamation but produce nonzero status; reconciliation moved
the final log write before receipt construction so its failure is included too.

Launchd installation targets the main checkout, uses a clean environment, runs
hourly at minute 17, preserves running jobs and restores the prior job after
bootstrap failure. Only the old marked cron entry is removed. Dry-run inventories
without deletion or native maintenance and preserves log history.

## Delete — do not maintain

- Removed the shell implementation, model invocation, mkdir lock, unchecked
  pipelines, checkout-wide cwd retention and redundant native build-prune call.
  The Python runner preserves mechanical scheduling, native source-pruning
  authority and Home retention. Rust verification recovery remains unchanged.
- Replaced `_builds(checkout)` and the immediate-child/three-level discovery
  loop with one bounded discovery path. Preserve the existing measurement,
  activity, Git, retention and removal checks for every discovered candidate.
- Removed the global Xcode `parts or [path]` fallback: after reclaiming Build and
  Index, a later cycle must not promote the remaining project/package source to
  a whole candidate. Source-tree and Xcode selection now have separate branches.
