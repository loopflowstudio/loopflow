# LOO-807 — operation identifiers

The Task directive calls for mechanical Rust variant and Swift case renames to
match dotted wire kinds, without changing the protocol. The current auto Graph
owns delivery as one PR.

Use PascalCase in Rust and lowerCamelCase in Swift, splitting dots and
underscores. Keep serialized kinds, fields, CLI arguments and results unchanged.
DTO/model names and RegistryQuery convenience methods remain outside this cut.

## Delete — do not maintain

- Old `Read`/`Write` variant spellings and `ServedRead`/`ServedWrite` cases;
  migrate every constructor and match, with no aliases.
- Swift `ConfigOperation`'s short cases and `ServerOperation.attach`:
  use the complete `config*` and `sessionAttach` operation names.
- Swift `desktopSessions` and `sessionPage` cases: one `sessionList` case
  carries optional cursor and limit, as Rust already does.
- Swift `taskOwnership`, `dashboardPin(pinned:)`, `dashboardTile(hidden:)`:
  separate cases for the existing claim/unassign, pin/unpin and hide/show kinds.
  Keep convenience methods that choose between them.
- `ServedWrite.option`: use `argument` directly; the wrapper adds no behavior.
- `ConfigOperation.Keys` and its nested kind switch: use `TaggedFields`, so
  each operation names its kind and fields together, as served reads/writes do.
