# LOO-807 — operation identifiers

Rust variants and Swift cases match dotted wire kinds, without changing the
protocol. The outcome remains one PR.

Use PascalCase in Rust and lowerCamelCase in Swift, splitting dots and
underscores. Keep serialized kinds, fields, CLI arguments and results unchanged.
DTO/model names and RegistryQuery convenience methods remain outside this cut.

## Concept review — 2026-11-08

Outcome: nothing to change; no open product choice. Continue to gate through
the existing Graph. This review adds no implementation direction.

The experience stays the same: list Sessions, page through them, claim a Task,
or pin a Dashboard. An operation has one wire kind and the matching language
identifier. Pagination is an argument of `session.list`; claim/unassign and
pin/unpin are separate operations. Convenience methods still express the
caller's intent without exposing transport spelling.

The source walkthrough covered a Dashboard pin through Swift encoding, Rust
dispatch and the existing Dashboard command. Its ID and revision still reach
the same owner. A failed request retains the existing error contract; an
`outcome_unknown` requires inspecting state before retrying. Renaming a case
adds no retry, persistence or execution lifecycle.

Counterexamples checked: a cursor without a limit remains invalid in the served
read; only the unpaged Session list supports subscription. The page helper still
supplies 100 rows. Configuration theme read/write remains one operation because
both use `config.theme`; splitting by UI action would invent a distinction the
wire does not have. No schema migration or protocol revision is implied.

The server README already describes the naming rule; CLI usage and skill
instructions need no changes. Next show the unchanged wire fixtures and served
behavior at gate. This was source review, not a new runtime check.

## Current implementation

The renames and consumers are implemented without aliases. Swift has one
`sessionList` case with optional cursor and limit, and distinct claim/unassign,
pin/unpin and hide/show cases. Convenience methods retain their behavior,
including the 100-row session page. Configuration encoding uses `TaggedFields`;
the redundant write argument wrapper is gone.

On 2026-11-08, remote `main` was still `1c757e9fe` (merged PR #1813), already
the branch's base. No upstream adjustment or product decision was needed.
