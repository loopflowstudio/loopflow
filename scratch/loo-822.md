# LOO-822: live Session state and usage from provider transcripts

Design: `docs/dev/server-first.md` (Telemetry). LOO-819's own plan is
`universal-server.md`; this file covers only LOO-822.

## Exists

- `transcript/live.rs` reads a Claude or Codex transcript's tail into a
  `SessionTurn` (state, start, end, model, usage); a half-written last line is
  left out. `transcript/raw.rs` finds `claude`/`codex` processes with no `lf`
  or provider ancestor. `transcript/watch.rs` keeps one watch per provider
  home in the Machine server and hints the shared `observe` cache.
- `lf session list` and `lf session card` carry `turn` and `raw`; Rust and
  Swift DTOs, schema and fixtures updated. A Session with a hook-recorded turn
  reports its boundaries from hooks, without model or usage.
- Docs: `docs/sessions.md`, `docs/surfaces.md`, `docs/dev/server-first.md`.

## What the transcripts carry

Read 2026-11-10 on this Machine: the 8 newest Claude 2.1.322 transcripts for
row keys, the 60 newest for `cost-state`, and 6 Codex 0.167.0 rollouts.

| Fact | Claude transcript | Codex rollout |
|---|---|---|
| Tokens | per `assistant` message `usage` | `token_count` last and total |
| Model | `message.model` | `turn_context.model` |
| Turn wall time | `system` `turn_duration.durationMs` (not every turn) | `task_complete.duration_ms`, `turn_aborted.duration_ms` |
| Stop reason, errors | `message.stop_reason`; `system` rows of subtype `api_error` | `turn_aborted` |
| Provider version | `version` on each row | `session_meta.cli_version` |
| Cost | none per turn; `cost-state.totalCostUSD` | none |
| Model time | none per turn; `cost-state.totalAPIDuration` | none |

Contrary to the first reading ("live `result` only"): 25 of 60 Claude
transcripts hold a `cost-state` row with `totalCostUSD`, `totalAPIDuration`,
`totalDuration` and per-model `modelUsage.<model>.costUSD`. It was the last
row in 24; one resumed transcript had six, mid-file. These are totals, not
per-turn values. Not established: what they total (process or conversation),
when Claude writes the row, and why 35 transcripts had none. An earlier pass
noted `isApiErrorMessage`; it was in none of these 8.

An unanswered `AskUserQuestion` shows as a `tool_use` with no `tool_result`.
A tool waiting on a permission prompt looks the same as a tool still running
(from the row shapes; not exercised).

## Remains

1. Fold the live read into the LOO-614 readers: `claude::turns` and
   `codex::turns` gain turn end, model and usage; `live.rs` `claude()` and
   `codex()` are deleted, leaving the tail window and `SessionTurn`.
2. Write `usage` and `completed` rows to `session_events` from a transcript,
   in the payload shape `harness/fact_writer.rs` writes from the live stream,
   deduplicated against rows hooks already wrote. A bare run gets them at exit.
3. "Waiting on you" from the transcript for bare and raw conversations:
   unanswered question, or an ended turn. `docs/sessions.md` says such a turn
   reads as `turn running`; that sentence changes with this.
4. One function decides which Task a conversation counts toward. Raw rows
   today match only the repository containing their cwd, in
   `ops/human_session/turns.rs`.
5. PR body: the per-harness table above, and which readers need `observed`
   rows. This branch's reads use only `started` and `completed`.
6. The Task's demo, with a real `claude`, has not been run.

## Open

- History's `Turn` starts at every request, injected ones included; a live
  turn is one agent run (Claude to `end_turn`, Codex `task_started` to
  `task_complete`). `Turn` is on the wire (`server_schema.json`, Swift
  `RegistryQuery`). Either `Turn` gains end, model and usage and one run
  spans several of them, or the readers return runs that hold the requests.
- A raw conversation has no Session ("Listing it creates no Session" in
  `docs/sessions.md`) and `session_events` rows belong to one. Either
  observing a raw conversation creates a Session, or its rows wait until one
  adopts it and are lost if the transcript expires first.
- Bare launches still run under an owner with hooks until "Bare launches go
  direct" lands, so nothing calls an exit read yet. Either this Task adds the
  call on today's owner exit, or it ships the function and that piece calls it.
- Claude cost per turn: nothing in the transcript gives it. Either a bare
  run's rows carry the `cost-state` total on the last turn, or cost stays
  absent for transcript-sourced rows.
- Raw conversations in plain `lf session list`: by default, or behind a flag?
