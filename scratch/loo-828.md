# LOO-828: identity in the context block, child-agent guidance

## Built

- Start and compact context blocks open with `This Session: <id>` and, when the
  Session has exactly one Task, `This Session's Task: <identifier> "<title>"`.
  Tool boundaries stay steers-only. The hook (`lf::commands::context::session_identity`)
  renders the lines into the steer prefix from the `LF_PROVIDER_CONTEXT` adapter
  every native launch installs; a store read failure drops only the Task line.
- Docs: `LOOPFLOW.md` rename line and `work` `--session` line point at the
  context block; `work` gains `## Child agents`; `docs/agent-api.md` gains
  `## Run a child agent`; `docs/work.md` updated. Prompt goldens regenerated.
