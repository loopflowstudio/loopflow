Capture Session/Task identity in the existing delivery file before provider
launch. Bare headless hooks read that file without a server or database.
Managed start/compact boundaries refresh its identity through the server's
store. Render identity in the bounded context prefix, never fixed instructions;
tool/stop boundaries remain unchanged. Keep the existing child guidance.

### Delete — do not maintain

- `lf::commands::context::session_identity`, its hook-side `hook_store` lookup,
  and its exclusive unit test: removed by the sync resolution. Retain Session
  and single-Task naming, escaping, startup/compact output and tool silence
  through delivery/server tests and launch assertions.
- The old post-render prefix fallback: identity now reserves bytes before
  file selection. The first integrated launch test caught the old fallback
  dropping `CURRENT_SCRATCH` from a nearly full block.
- The scanning `session_task_ids` query: reuse the indexed `session_tasks`
  membership query introduced by LOO-821.
- `prefixed_block` and the duplicate launch-file writer: removed. Both block
  entry points now render identity through `block_with_prefix`; `emit_block`
  keeps tool boundaries steer-only. `configure_hooks` uses the atomic `save`.
- The hook test's `support::EnvGuard`: each child already clears and supplies
  its environment and binary. Keep only the shared environment lock. The
  compress run found this guard rebuilding the CLI before testing any hook
  (`/tmp/loo-828-compress-integration.sample`).
