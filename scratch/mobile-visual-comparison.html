06 / Proposed next pass

Show one believable
phone interaction.

These recommendations refine the two selected screens. They do not settle the service architecture, terminal library, control handoff or geometry ownership.

01

Open the keyboard

Compact the Task header. Show how much terminal remains, how typing reaches the live prompt, and how hiding the keyboard restores context.

02

Edit and answer a real prompt

Show cursor movement, a multiline correction and one agent menu/permission question. Try the minimum arrows/modifiers/paste controls that make those work.

03

Leave and come back

Switch Tasks, background the app and disconnect. Preserve the exact Session and local presentation; never submit preserved text or uncertain keys automatically.

Native proofRun those interactions on a phone with real terminal bytes, touch selection, dictation/IME and an external keyboard. The source screenshots cannot establish latency, process survival, accessibility or reconnect correctness.
