# LOO-1067 · Redesign the file browser

> Jack Heart, November 22: “lets do directions 1 and 2”
>
> “4a i think --read only by defautl / easy to turn on editable”

**Done when** you can find a file in an unopened folder, preview it, jump from a call to a declaration and back to the same line, and put a comment on those lines into the Task conversation. An agent can present a finished page beside that conversation. While you read, edit or review, ordinary writes leave your place and keyboard focus alone. Desktop reads files from the Machine that owns the checkout. Both directions land in one PR. The [Round 3 prototype](explore.html) and [design](design.md) show the chosen layout.

## What appears in Files

Keep Brief, Diff and Files in the pane strip. Files has one 32-point header with a sidebar button, jump history, a path breadcrumb and document actions. A folder segment opens its siblings. The filename switches or closes open files, and the enclosing symbol follows the reading position. Open files are also at the top of the empty file picker. This is the choice for review over a second tab row. Keep the recorded Machine and full path accessible from the breadcrumb.

The 236-point rail docks at 620 points and opens as a dismissible drawer below that width, using Diff's layout and named design tokens. Open & Scratch shows drafts and updated paths. Changed in Task shows counts from the whole Task. Checkout keeps keyboard navigation, paged directories, retries and scroll position. Compact single-child directories only once their listing is complete. Reveal the selected path through its ancestors. Changing Show Ignored starts a fresh listing because Rust directory cursors include the ignore setting. At 360 points the header folds actions into its menu and a file pick dismisses the drawer. [CheckoutTree.swift](../swift/LoopflowMac/CheckoutTree.swift) · [TaskChangesView.swift](../swift/LoopflowMac/Views/TaskChangesView.swift)

Files opens in Read. Code has grammar colors, selectable numbered lines and change marks. Markdown and HTML render, and images open as pictures. A visible Edit button and **⌃⌘E** toggle the same retained text document, including unsaved text, caret, undo, IME composition and save recovery. The shortcut is a kickoff choice. Changed files also offer their draft-aware Diff. The top-level Diff keeps its whole-Task and step comparisons, review layouts, tour, viewed state and delivery card. Keep every current grammar, filename association and plain-text fallback. [Grammar.swift](../swift/LoopflowMac/Grammar.swift) · [LOO-1040, PR 2013](https://github.com/loopflowstudio/loopflow/pull/2013)

Click or Shift-click a line in Read or Diff to comment, copy or reference a range. Use the same editor, strip and pending comments in both places. Today a patch refresh detaches every comment whose file is absent, and batch formatting describes everything as “on the diff.” Give each selection its source (working document or comparison side and revision) and captured lines. Re-anchor against that source only. An ambiguous or vanished anchor keeps its original reference and says the lines changed. ⌘↩ inserts the batch into the conversation's **unsent input**. An unavailable conversation or failed insertion leaves the queue intact. ## How a file gets shown

LOO-581 introduced scratch following for presenting explore pages. LOO-515 later put Brief, Diff and Files in one Task pane. Today an explicit presentation and a passive write both enter `TaskFilesStore.follow`. After 120 idle seconds either can change the selected page. The two operations now have separate effects. [PR 1687](https://github.com/loopflowstudio/loopflow/pull/1687) · [PR 1949](https://github.com/loopflowstudio/loopflow/pull/1949) · [TaskFileDocument.swift](../swift/LoopflowMac/TaskFileDocument.swift)

- On first entry to an empty Files pane, after restoring tabs and drafts, show the newest eligible scratch Markdown or HTML page. Rust currently sorts scratch paths alphabetically. Have the Machine report the latest eligible path from the existing bounded scratch walk by modification time, with a stable path tie-break. If none exists, show the first changed file or the empty picker. Closing the last tab, a later write or viewing Brief/Diff never repeats this initial choice.
- An observed write badges its path. The quiet update bar offers Open, coalescing repeated writes to one path. The event contains only a path, so the bar reads “Updated scratch/explore.html”. Reconcile open documents normally, including hidden dirty drafts. For the visible HTML document, keep the rendered page while writes arrive, reload once after 800 ms of quiet, then restore scroll. Initial opens are immediate. On disconnect retain the draft and offer Refresh. Keep offline HTML rules, external link handling and remote base-URL behavior.
- `lf open --host desktop --file scratch/explore.html` deliberately presents the page in the existing Task Files pane. Repeated paths reuse their tabs. Repeated flags retain all requested files. Preserve other drafts and their undo history. The existing command already resolves local and remote targets, and reports when Desktop is absent. The explain probe resolved this checkout's page with `"opening":false`. Follow the existing `write-docs` example in builtins that finish a review page (explore, concept-review, demo, research). The point to present is when the artifact is ready to read. [open/files.rs](../rust/loopflow/src/lf/commands/open/files.rs) · [write-docs.md](../rust/loopflow-definitions/src/builtins/task/skill/write-docs.md)

## Search, symbols and ownership

**One picker** has Files (⌘P), Grep (⇧⌘F) and Changed modes. Arrow keys preview without changing tabs, history or selection. Return opens the selected line. Escape returns focus and place. A wide pane shows a syntax-colored preview centered on the hit alongside results. Narrow panes show the list first. Fuzzy path ranking favors scratch, changed and open matches, then match quality and path. Changed uses the existing whole-Task comparison even after visiting a step Diff.

**The recorded checkout supplies disk results.** Add three reads in the existing `ops/task` → `Read` → `RegistryQuery` path. Give each a CLI equivalent alongside the existing directory command, e.g. `lf task files <issue> --index`, `--grep <text>` and `--symbols <name>` (outline by path). Wire kinds are `task.files.index`, `task.files.grep` and `task.files.symbols`. Keep CLI execution, SSH routing, served argv/results, generated server schema, Rust and Swift fixture decoding in agreement. Required nullable keys are present on the wire. The Mac never enumerates a peer's path. [read.rs](../rust/loopflow/src/lf/commands/read.rs) · [RegistryQuery.swift](../swift/Loopflow/Services/RegistryQuery.swift) · [served reads](../rust/loopflow/tests/served_reads.rs)

- Enumerate tracked and nonignored untracked paths with the checkout's existing Git, plus bounded scratch entries, deduplicated. An isolated probe with a tracked `*.log`, an ignored log, a hidden directory, an unopened directory and ignored scratch found that `rg --files --hidden` lost the tracked log. Git kept it. Both omitted ignored scratch. Use this inventory for paths, Rust grep and declarations. The existing peer watcher also filters ignored scratch. Pass eligible scratch page changes through there while keeping journal and build noise out. Keep reads within the checkout across symlinks. Skip deleted entries on search and keep existing explicit symlink reading behavior. [snapshot.rs](../rust/loopflow-execution/src/ops/task/snapshot.rs) · [workspace.rs](../rust/loopflow-execution/src/ops/task/workspace.rs)
- Page path results (500 per reply). Match over the complete inventory before capping ranked results. Grep uses the ripgrep Rust matcher/searcher with a literal query by default and returns path, one-based line, match span and bounded excerpt. Limit grep and symbol replies to 100 hits with a visible truncation indication. Use UTF-8 byte spans on the wire and convert to AppKit UTF-16 ranges against the matching revision. Observe the existing 1,000,000-byte text ceiling. Binary, invalid and oversized files keep their existing viewer states. An empty query shows recent/open files in Files and an idle Grep. No hits, incomplete results and failed reads each have distinct UI.
- Parse declarations on the owning Machine. The Mac's XCFramework supplies coloring but cannot execute on a Linux peer. Use portable pinned Tree-sitter grammars for Swift, Rust, TypeScript/TSX, JavaScript/JSX, Python, Go and Markdown headings. Language-specific declaration patterns provide best-effort results elsewhere. One set of declaration queries serves outline, enclosing symbol and checkout definition lookup. For the open document use the retained buffer, including dirty text, with the same queries in the bundled parser. Replace that path's disk results with its live results in the UI. Do not send unsaved drafts during repository search. A probe with the repository's Rust grammar version (0.24.2) found both `render` methods on lines 2 and 3 of a CRLF file and excluded the call on line 4. [grammar pins](../third_party/manifest.json) · [Swift package](../swift/Package.swift)
- ⌘-click or `gd` jumps to one matching declaration. Several definitions open an inline list with enclosing name, path and line. Zero hits leave the location intact. A truncated set cannot establish uniqueness. `gr` lists whole-identifier text occurrences as reference candidates. This is syntax navigation without language servers or type resolution. ⇧⌘O opens the outline. Only accepted jumps push a path and position onto history. Back/Forward restore it. Character chords belong to the focused code reader.
- Cache path inventory and per-file declarations in bounded Machine memory through the existing observation mechanism. Key inputs by checkout and file revision. Membership, Git index and ignore changes invalidate the relevant results. No SQLite writes on typing or background indexing across all Tasks. Start lazily when the picker or symbol action opens, debounce typing, cancel superseded scans, and accept replies only for the current owner, checkout, query and document generation. A slow peer can delay results without delaying typing or showing an old preview as the new selection. [observe.rs](../rust/loopflow-execution/src/observe.rs)

**Find belongs to the focused pane.** Ghostty already rejects key equivalents while another view is first responder. Files needs a responder for its noneditable surfaces and a focused command that also respects the find field, editor, WebView and IME. ⌘F opens one inline bar with count, Enter/Shift-Enter stepping and promotion of the same query to Grep. Search the text shown in Read lines, live editor ranges, Markdown block cells, rendered HTML text and visible Diff sides. Markdown already exposes block anchors. Use the installed WebPage SDK’s `callJavaScript` in an isolated content world. Pass the needle as an argument, count visible text ranges and reveal the selected range without reloading. Images show no text matches. Route ⌘[ / ⌘] before the global Desktop history monitor while Files owns focus, and route ⇧⌘O before the Open Repo menu shortcut there. Terminal Find, window navigation and Open Repo still work in their existing contexts. ## Build order

1. **Jump in a remote checkout.** Deliver the smallest vertical path through both directions. ⌘P previews an unopened Rust file on the owning Machine, Return opens it read-only at a line, and ⌘-click on a method with two definitions produces a peek. Choose the second and go back. This exercises the riskiest contracts together across remote reads, grammar packaging, coordinates and focus. Replace the old expanded-folder ⌘P search at this point.
2. **Read in place.** Land the breadcrumb and rail, one-time initial choice, update signals and deliberate presentation. Remove the three-state navigator, pin shortcut, static location row, tab counter, follow timer, interaction bookkeeping and passive document/tab creation. Retain tab IDs, tree pages, failed-read retries, drafts and layout restore. Update the old pin, “1 of 3”, stale-attention and explicit-present tests to assert the visible replacement. Move open-file readiness timing to the displayed reader.
3. **Find and review.** Finish every renderer's ⌘F, promote to checkout Grep, fill out Changed and preview, and connect line comments and change marks to the existing queue. Reuse the Diff editor and strip. Reconcile view, focus and edit/save tests and the Files section of `swift/README.md`.
4. **Complete navigation.** Exercise all core grammars and fallback, outline, enclosing breadcrumb, references, dirty-buffer overlays, invalidation and truncated results. Update the command reference and server resource table with CLI equivalence. No change to iOS navigation or the existing Diff comparison controls.

## Gate and demo

Planned headless gate from the repository root, with the source-built CLI and the new Swift integration scenario:

```sh
cargo build -p loopflow --bin lf
swift test --package-path swift --filter TaskFileBrowserJourneyTests
```

One isolated Task on a fixture Machine contains an unopened source file, two same-name definitions, Unicode before a hit, an ignored scratch page and an excluded build artifact. Run the journey through the CLI and through Desktop's served reads using `BuiltLf`. Repeat the Swift journey with a peer checkout absent on the presentation Mac. Expect matching path/line results, a preview that leaves selection alone, two definitions, a working return jump and a single batch of Read and Diff comments in unsent conversation input. A scratch burst while reading, editing or on Brief/Diff must leave page, caret and focus in place. An explicit presentation opens its page. Returning to Edit restores the draft. Exercise the real find-command target on reader and terminal, narrow/wide layout, and an out-of-order reply. Use deterministic event delivery for settling and a mounted native key-event check in display-capable QA. This is the acceptance test to build. The kickoff probes exercised enumeration, parsing and explicit target resolution only.

## Demo
