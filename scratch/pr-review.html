4. What “Task run” means

Jack asked what a TaskRun is. There is no TaskRun type or table. A Task run is one attempt by lf task run to traverse an edge; retries can produce several child Flow processes. The Task-run Process and Workflow move history represent that attempt.

TaskRunControl says why execution is unavailable. Desktop’s TaskRunDraft contains only an in-flight flag and error for run/move commands; it is transient UI state, not another attempt record.

The base combined recommendation, latest execution and Start controls in TaskFlowSnapshot. This PR separates those readings without introducing a new lifecycle. FlowDefinition is authored execution, FlowComposition is its expanded disclosure tree, and FlowProcess records one driver and its steps.
