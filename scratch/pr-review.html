Inspect a command as a process

PR #1483 replaces Loopflow’s Exec vocabulary across the CLI, Desktop, Rust, Swift and storage. Each process exposes a durable lfid and an optional Unix pid. Historical PIDs can repeat without combining records.

Implementation source: 1a2c42ee3f596bbb44c1c411c7a1b606eb31baaf. Compared with 6448e3c9e7e519585378feaffe04606bc1b55d3e. This walkthrough adds no product changes beyond that source. Jack Heart approved the LFID/PID refinement and landing on October 7; installation remains separate.

Inspect by durable identity

Captured in a disposable Home using the built source CLI. JSON below is an excerpt; other fields are omitted. The PID matched the child spawned by the check.

lf monitor show e525a36e-2fd5-4e7a-bed8-506cd40e0cea --json
{
  "lfid": "e525a36e-2fd5-4e7a-bed8-506cd40e0cea",
  "pid": 74385,
  "parent_process_lfid": null,
  "outcome": "succeeded",
  "exit_code": 0
}

Compared with the base, Exec.id becomes Process.lfid; pid is new and nullable. The ordinary journal records std::process::id() at admission. Swift mirrors these fields and derives its Identifiable key from LFID.

A PID can name several historical commands

The update key is LFID. PID supplies observed OS identity, not authority to signal a live process. Existing exact receipt and birth-time checks still own liveness and control.

A Flow still consists of its one lf process and the step processes it starts. The rename adds no lifecycle owner. Flow projections read their additional columns by name, so adding PID does not shift the Flow name or step position.

Keep the old evidence readable

The single draft upgrades the released schema directly. SQLite rewrites retained foreign-key references. Existing rows receive a null PID; neither current process lists nor a reused PID reconstruct missing evidence.

The initial rename missed released boot-witness JSON. The repaired reader and regression preserve that witness, provider generation and native thread after restart. Capture manifests and process receipts also keep their existing encodings; public DTOs expose only the new names. A missing receipt still leaves exit evidence unknown.
