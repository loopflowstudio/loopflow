Home becomes machine

The goal is a vocabulary change with no behaviour change: the place work runs is called a machine everywhere a person reads or types it, and in code, wire fields and schema. What already exists on disk keeps working. Machine registration, credentials, detached work and pane restore are later PRs and are not here.

What you type

Review note. lf machine still owns desktop, screenshot, install and doctor, which are about the installation, not about where work runs. LOO-401 moves those. One hidden subcommand, sync-skills, is carried over unchanged.

Identity and schema

A machine is an id and a route. The type is renamed; the stored value is not.

Review note. This is the lower-risk option the design offered: keep the persisted home_ ids and rename everything around them. The landing-history discriminator value 'home' is also kept as historical evidence, with the triggers that forbid new rows using it recreated under new names. Older migration files still say home; they are shipped records.

Reaching another machine

Consequence. The check runs lf machine id on the remote. A remote still on a release that only knows lf home id fails with "remote lf could not read its MachineId". The laptop and the mini have to be upgraded together for lf ssh <machine-id> to keep working. A raw host name as the target skips this check, as before.

This PR also deletes capture_home_command from the same file, which had no callers (ssh.rs: 43 lines added, 129 removed).

Data already written by released versions

Three places keep the old spelling so that data on disk still reads.

Review note. The receipt alias and the launchd key protect durable records and installed jobs. The cache translation protects a display cache whose own header says "the first successful read of each part replaces it". Discarding version-1 files would be simpler than translating them, and the function that does the translating guesses that a home object with route and id is a machine. This is the one retention worth questioning.

Open points

  • Keep or drop the Desktop cache translation. See above.
  • "Machine" still has a second meaning. The design asked for the install-scope use to be settled. docs/architecture/machines.md still says "machine promotion lock" and docs/troubleshooting.md says "Machine commands can have no repository". Settle here, or leave for LOO-401.
  • Mixed versions. Upgrade every machine you reach by id at the same time.
  • Callers of lf home and readers of home_id in JSON break. The Mac app is updated in this PR. Anything outside the repository is not.
