3 · Which Flows ran and how they ended

The Flow's id is its driver's process id. Its state is the driver's outcome: running is Current, a clean exit is Completed, anything else is Stopped. Its Task is whichever Task's worktree contains the driver's directory.

What was given up. No graph is pinned at launch. A Flow is drawn on today's authored graph only while every recorded step still fits it; otherwise it is drawn as the flat sequence its steps recorded. Recorded as accepted by default, not confirmed by Jack.
Fixed since the first review. A failed Flow read Current beside a line saying its process exited. It now reads Stopped.
