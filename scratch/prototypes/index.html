LOO-515 · Task details beside the conversation

Three different ways to arrange the brief, PR, changes and checkout next to the Task conversation. Each uses the real LOO-515 brief and this checkout's 1,458 files. Use the Prototype states panel (bottom right) to try no PR, stale or unavailable GitHub, merged, long/empty/changed briefs and an offline Machine. Press ⌘1/⌘2 to switch Tasks and check that everything is where you left it.

A · Pages

The kickoff draft. One header names the Task; a Brief · Changes · Files switcher (⌥⌘1/2/3) flips the whole pane. PR state sits on top of Changes. Files is a docked tree plus document tabs, with a location line. Familiar, compact, one thing at a time.

 B · Dossier

One scrolling page that reads top-down: outcome, numbered acceptance, PR, changes, checkout tree. A sticky header holds identity and status, with section jumps. Opening a file slides a sheet over the dossier, with a breadcrumb, prev/next through changes, and Esc back to exactly where you were.

 C · Navigator

A Task strip spans the window, so identity and PR state stay visible over the conversation too. The details pane is a navigator plus viewer: Brief, Pull request and Changes are entries above the checkout tree, so everything opens the same way. ⌘K go-to, ⌘[ / ⌘] history.
