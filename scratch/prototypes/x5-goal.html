Goal

Loopflow is where you designimplementdemoship software with agents.

We’ll get you building whatever software you want like a software engineer, by guiding you through workflows that get the most out of you and ensure high quality software, not slop.

You need

  • A coding agent (Claude Code, Codex, or OpenCode)
  • A GitHub account

What you get · 8

  1. A terminalAt its most basic, Loopflow for Mac is a terminal. Open a repository and start a Session with Claude Code, Codex, or OpenCode, the same way every time.
  2. SkillsStart a Session from a Skill instead of an empty prompt, so you stop retyping how you like work done. Pick one when you open the Session.
  3. SessionsEvery conversation is kept, whichever agent ran it. Close the window and it is still there when you come back.
  4. Waves and TasksThe sidebar is your work, not a list of chats: Waves (long-lived streams), the Tasks under each (concrete outcomes, i.e. PRs), and the Sessions under each Task.
  5. One Task, one copy of the codeEach Task works in its own copy, on its own branch, toward one pull request, so many agents can work without colliding.
  6. WorkflowsA Task’s header shows the stages it goes through to become a shipped and validated PR: where it is now, and where it waits for you.
  7. Waiting on youA Task that needs you is marked, so you look where you are needed and leave the rest running.
  8. Side by sideSplit the window to follow several Sessions, or several Tasks, at once.
Download for Mac

Free and open source. The coding agent it drives runs on your own account and has its own cost.

A drawing in the shape of the app: a goal, what it needs, and its tasks. The real thing is below.

  • It is yours Your code stays in your GitHub and on your Mac. Nothing is hosted, so there is nothing to move off later.
  • Change whatever you want Skills are Markdown and Flows are YAML. Edit them or use the built-ins. MIT licensed.
  • Underneath, it is all lf The Mac app includes the command line tool, and every pane is a terminal that runs it.
