# Choices made for review

- **Unify Desktop and Mobile through server-side Task routing.** Passed over keeping Desktop on its client-side `RegistryQuery.onMachine` (CLI-over-SSH subprocess fanout + double `ssh lf task location` probes) while adding server forwarding only for Mobile. One pooled `Connection::open_on` router on the Loopflow server serves Files, Changes, Diff, Save, Shell, and Session for both clients, deletes the duplicate stack, and prevents local/remote split-brain.
- **No rental-only “carried selection” side channel for Wave Projects.** Passed over inventing rental-specific Wave Project state. Cold acquisition binds the sole In Progress Linear Project on any fresh clone; when an Initiative has multiple In Progress Projects and the source Machine picked one, rental `prepare` uses the existing public `lf wave plan bind` command.
- **Keep `lf open` always local when `--machine <label>` is given.** Passed over making root `--machine` forward `lf open` onto a headless container or adding a second flag name (`--from`). Both `lf open --machine <label> --session <id> --tab` and `lf --machine <label> open --session <id> --tab` present here and attach on `<label>`.
- **Use Modal’s published minimum of `0.125` core and `128 MiB` as the burst floor.** Passed over `0.25` core / `256–512 MiB`; the floor can be raised later against measured workload.
- **Resolve packaged Linux builds on the caller.** Passed over baking a moving stream into the shared Modal image, which would require rebuilding per release and fails before remote GitHub auth exists.
- **Make overwriting forwarded files explicit (`lf machine forward <label>`) with opt-in targeted restart (`--task <id>` or `--session <id>`).** Passed over clobbering destination files on ordinary launch or restarting all provider Sessions automatically, so rotating one login does not interrupt unrelated work and targeting a Task’s primary Session does not require looking up a remote Session UUID.

- **Record the Modal sizing mode at admission.** Old declarations live in personal YAML, while old rentals keep their hardware in SQLite. A missing mode on a declaration selects burst for the next create. A missing mode on a recorded rental retains its original full request and unbounded maximum. Only a recorded burst or reserved mode carries `ceiling_estimate_usd`.

- **Pin packaged dev builds by GitHub Actions run ID.** The main package workflow checks out the triggering CI run's revision. Its own workflow head can already have advanced. Recording its run ID lets a packaged caller fetch a sibling Linux artifact directly. Clean source builds look up their commit, and the serving binary must match the uploaded bytes.

- A repeated explicit placement treats an existing Graph run on the recorded owner as an acknowledgement. Plain `lf task run` remains the command to advance it. If the owner cannot be reached, placement stops before admitting another rental.
- Count In Progress Projects across the complete Initiative before filtering to the repository Team. A second active Project outside that Team makes the automatic choice ambiguous.

- Collection resumes by changed Session in the source state and history databases. Give-back revisits closed Sessions too, because provider and capture files can finish after a database write. `lf session usage --session <id>` totals the selected Session’s turns on its recorded origin. The existing work-scoped input reports keep their Machine-local attribution.
