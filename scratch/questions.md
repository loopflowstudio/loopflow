`runs_on` names an unregistered Machine by the public name its claim carried, else its id (existing ownership labeling). A sandbox without a public name shows as its id; giving rentals a public name would make `Runs on modal-3` literal.

Desktop's board does not show a `runs_on` badge yet: Swift ignores the `runs_on` key. Slice 4 sets `actions` to `no_action` and drops local `unstarted` from `selection_states` for open Tasks running elsewhere so Desktop stops offering Start/Run on them.
