Asana admission uses the team GID and repository project name, the pair Asana resolves before reading Tasks. The watermark also records the resolved project GID so replacing that project resets its delta.

`runs_on` names an unregistered Machine by the public name its claim carried, else its id (existing ownership labeling). A sandbox without a public name shows as its id; giving rentals a public name would make `Runs on modal-3` literal.

Desktop's board does not show `runs_on` yet: Swift ignores the key. `actions` (Run buttons) for a Task another Machine runs are unchanged; only `next` and the reason are.
