# Machine authority and an optional public hub

Research for Jack Heart · November 3, 2026. Historical evidence, not new direction.

Machine identity is an OS account/data authority, not an address or Tailscale principal. Task claims tolerate disagreement and are not distributed exclusion locks. A future hub may own durable ingress and explicit execution grants, but not Task/Graph execution. Event refresh may fan out; one named Machine receives execution. No hub capability is part of this slice.
