# Historical LOO-593 scope

Jack Heart's October 25 request followed LOO-519/PR #1677: investigate the roles
and architecture of Desktop's app-owned automation server. Its original questions
covered command/URL routing, discovery, remote access, permissions and lifecycle.
The November 4 [accepted design](../mobile-backend.md) selects a separate shared
client API server and preserves app-owned UI automation. Unselected automation
extensions remain future questions.
