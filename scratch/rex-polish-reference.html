Rex Polish for Loopflow

Superlogical's Rex has a look other terminal apps are copying. This guide takes the eight elements behind that look and sketches each one on Loopflow Desktop as it stands today, with what people would likely enjoy and what it would cost.

“Pretty easy to demonstrate causality since the style didn't exist before (the combination of all the elements, not any one thing individually).” Mitchell Hashimoto, October 13, 2026

1

Islands

In Rex, every terminal is a rounded card floating over the window's wallpaper or gradient. A compact mode switches back to single-pixel borders. Alasdair Monk, Sep 8

@@ SessionsView · WorkspacePanesView @@
- panes share one charcoal plane, split by a 1pt line at 12% opacity
+ each pane is a card with a ~10pt radius and a 6pt gap to its neighbours
+ the window ground (cream, or a soft wine-to-cyan wash) shows between cards
+ the focused card is lifted with a shadow; the others stay flat
+ a Compact setting keeps today's 1pt dividers

What people might like

Panes read as separate objects, so a Task with an agent, lazygit and a dev server stops looking like one wall of text. Focus shows through elevation instead of a coloured border. It is the single change that most makes Rex look like a Mac app rather than a tmux skin, which is why copies like GoRex start here.

Tradeoffs

  • Every gap and corner costs terminal columns, roughly one or two per split at 13pt.
  • It reverses a deliberate choice. TerminalPalette.swift says the charcoal region should "read as the page rather than a panel."
  • It needs a compact mode for dense layouts, as Rex ships, so there are two layouts to test.
  • Shadows and rounded clipping add compositor work on every live resize.
2

Whole-app theming

Rex ships 41 themes that tint the entire application, not just the terminal, and its materials range from full Liquid Glass to solid system palettes. Alasdair Monk, Sep 8

@@ LoopflowPalette · TerminalPalette @@
- two fixed appearances, cream and slate, each paired with one charcoal terminal
+ a theme picker that retints the sidebar, headers, selection and terminal together
+ import of an existing Ghostty theme as the starting point
+ semantic roles (selection, focus, Working, Waiting, Failed) remapped per theme

What people might like

The window feels like one object instead of a cream app wrapped around a dark terminal. People who spent years tuning a Ghostty theme bring it with them on day one, which Rex makes a celebrated moment. In a tool open all day, making it look like your own is a strong reason to keep using it.

Tradeoffs

  • Loopflow's palette is semantic. WorkPaletteTests composites real colours and requires 4.5:1 for text and 3:1 for indicators. Each theme multiplies that matrix.
  • Status colours can clash with a theme's own hues. On a red-heavy theme, Failed stops standing out.
  • The burgundy identity in VISUAL_DESIGN.md weakens once the app can be any colour.
  • Rex keeps 41 themes up to date. That is ongoing design work, not a one-off.
3

Deck icons

Rex gives terminal apps favicons. A tab's icon stacks the tiles of the programs in its panes like a deck of cards, with the focused pane in front. The icons are drawn by human artists. Monk, Aug 4 · Hashimoto, Oct 5

@@ WorkNavigator · Task row @@
title / status · task · PR · Machine (unchanged)
+ a 16pt stacked icon: one tile per program open in the Task's workspace
+ the focused pane's program drawn in front
+ an empty slot for Tasks with no open workspace, so titles stay aligned

What people might like

You recognise a Task by its shape before you read its title. At a glance you can see which Tasks have an agent, a git UI or a server running, which the text metadata line can't show. Hand-drawn icons make a dense sidebar feel warmer.

Tradeoffs

  • A Loopflow Task is not a tab. Many Tasks have no open workspace on this Mac, or run on another Machine. Their icon would be empty or stale, which could look like a broken state.
  • It needs reliable program detection and a library of drawn icons. Rex paid artists for theirs.
  • The sidebar row was tuned for density on October 13. An icon pushes every title right and squeezes the metadata line.
4

Program-aware pane headers

A Rex pane header shows the program's icon, a friendly name ("Git Changes" for lazygit, "Node" for a dev server) and its folder, with split buttons. Activity Mode demo, Oct 11

@@ SessionsView · pane strip @@
- monospace terminal title, whatever the program last set
+ program icon and friendly name in the UI face
+ working folder (shortened) or a one-line program summary, dimmed
+ the OSC 7501 reason moves into the header's right edge

What people might like

With three or more splits you can find the right pane without reading terminal text. Headers stop depending on each program setting a good title, so pnpm, cargo and lazygit all label themselves sensibly. Loopflow starts with an advantage: lf launches the agent, so it already knows which harness is running in each pane.

Tradeoffs

  • Someone has to maintain the table that maps processes to friendly names and icons.
  • Detecting the foreground process (GoRex uses tcgetpgrp) gets unreliable inside ssh, wrappers and nested shells.
  • A wrong friendly name is worse than an honest raw title. Unknown programs need a plain fallback.
  • A wider header leaves less room before the hover-only split and close buttons.
5

Pill tabs and an operator sidebar

Rex switches between horizontal pill tabs for focused work and vertical tabs ("operator mode") that span sessions and machines. The vertical list is grouped by machine first. Alasdair Monk, Aug 27

@@ SessionsView · navigation @@
- the 320pt outline is the only navigation, always visible
+ Focus mode: pill tabs for open Tasks in the titlebar, sidebar hidden
+ Operator mode: today's outline, with an optional Machine grouping
+ the Machine name moves from row metadata to a group header
one shortcut toggles; selection, Back and retained panes are shared

What people might like

Focus mode gives 320pt back to terminals when you are deep in one or two Tasks. It is the closest thing to Jack's old cmux habit of a few tabs per repo window. Operator mode keeps the full picture for supervising many Tasks, and grouping by Machine answers "what is running on mini-heart" without opening each Task.

Tradeoffs

  • Two navigation surfaces must share selection, Back history and retained workspaces. LOO-462 has only just made that behaviour stable.
  • Tabs suggest an ad-hoc set of open things, while Loopflow's model says Wave → Task is the navigation. Deciding which Tasks get a pill is new state someone has to own.
  • Grouping by Machine competes with grouping by Wave. Today Machine is quiet metadata, shown only for remote Tasks.
6

Activity Mode

An eye toggle in Rex switches the sidebar to the active and idle processes and agents, with extra metadata for quick switching. It is driven by OSC 7501 program status, plus weeks of tuning on when to show which state. Monk, Oct 11 · Hashimoto, Oct 11

@@ WorkNavigator · WorkActivityView @@
- status shown inside each Task row, scattered across the Wave outline
- a separate Activity pane that lists history (Work creation, Runs, PRs, Steers)
+ an eye toggle that swaps the outline for a flat list of live programs
+ Needs you → Working → Idle, oldest wait first, across every Wave and Machine
+ the reported reason inline ("approve test run?"); Unknown is never listed

What people might like

It answers "what needs me?" in one glance without expanding Waves. Switching to the next blocked agent becomes one click. Rex's team says it is the first activity inbox they actually use, and people tend to remember the tool that gets them unstuck.

Tradeoffs

  • It is only as good as the status signals. Loopflow's rule is that Waiting is judged from owned provider streams and Unknown shows nothing. A feed of guesses would break that rule.
  • Monk called the timing "hard." An inbox that fires too eagerly turns into "email but worse."
  • The name clashes with the existing Activity history pane. One of them should be removed or renamed rather than kept beside the other.
7

Tab peek

In Rex, a three-finger swipe down shows live, Metal-rendered previews of the other tabs, splits included. Dragging further opens a Mission Control–style grid. The terminal slides down out of the way and is never resized. Mitchell Hashimoto, Aug 12

@@ SessionsView · retained workspaces @@
- checking another Task means selecting it, which swaps the main area
+ a swipe or shortcut slides the workspace down without resizing it
+ live thumbnails of the other retained Task workspaces, splits included
+ dragging further opens a grid of every Task; releasing returns without navigating

What people might like

You can't read thumbnail text, but its shape tells you plenty. A scroll of output means still working, and a short screen ending in a prompt means waiting. You check on other Tasks without leaving yours or losing your place, and because nothing reflows, coming back is instant. Mitchell says it becomes a reflex.

Tradeoffs

  • Live thumbnails mean rendering every retained Ghostty surface at once. That competes with the agent-input latency work this Task is profiling.
  • Tasks without a retained workspace have nothing to show, so the peek only covers what you have already opened.
  • Remote Machines need their streams attached. A peek must stay passive, since passive display acquires no claim.
  • A three-finger swipe can collide with the system Mission Control gesture, so a keyboard shortcut has to be the primary trigger.
8

Small touches

Rex has a shader flash when you copy text, a find bar that nudges itself off a match, automatic contrast correction for light themes, a Doom pixel-melt when the server is killed, and an animated update screen. copy · search · contrast · melt

@@ Ghostty surface · terminal chrome @@
- copy happens silently; the selection just clears
- the find bar floats over whatever text is underneath it
- program colours pass through unchanged, even when unreadable on a light background
+ a brief glow on the copied cells and a "Copied 2 lines" note
+ the find bar steps aside when it would cover the current match
+ low-contrast foreground colours corrected toward the theme (OKLab, cached)

What people might like

Each one fixes a small irritation people have stopped noticing. Copying over ssh is famously unreliable, so a confirmation removes the guesswork. A find bar that hides the match is a bug in nearly every app. Readable lazygit on a light theme means light-mode users stop switching themes just to read. Together they make the app feel cared for.

Tradeoffs

  • Every animation needs a reduced-motion version and must stay off the input path.
  • Contrast correction rewrites colours that programs chose on purpose, such as diff and syntax colours, and some people will call that wrong.
  • Loopflow's terminal is always dark today, so contrast correction only pays off if light terminal themes arrive with whole-app theming (section 2).
  • Whimsy like the melt can read as noise in a tool about getting work done.
