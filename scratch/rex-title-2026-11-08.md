Initial code observations in this checkout; these still need reproduction against the installed build:

- `naming::generated_session_title` excludes generic operator skills from title purposes but does not exclude `default`, so a bare Session can take that skill name ahead of its directory fallback.
- `TerminalTitle::prepare` writes OSC 0 once before launching the provider; Codex receives `tui.terminal_title=[]`.
- Subsequent updates use `HostNames`, which supports only cmux and tmux. `ViewerTitle::new` does not look up titles without one of those hosts. A stored rename therefore has no ongoing publication route to a plain Rex terminal in this code.
- The module explicitly avoids writing OSC alongside provider output because escape frames could be split. A repair must serialize terminal title updates through the output owner rather than introduce an independent writer into a provider stream.

## 5whys: why generic terminals kept the launch title

Two independent defects reinforced each other. With no request yet, naming
treated the `default` skill as the work's purpose, ahead of the directory
fallback. The generic-skill exclusions introduced in `3a0aa5ca44` (#1510) omitted
`default`; the old directory-fallback test exercised `wave-operate`, not the bare launch's
skill. The recorded red naming test produced `default` instead of
`terminal-titles`. Fixing publication alone would faithfully publish that poor
initial name; fixing the fallback alone would still leave later renames invisible.

The publication gap was an explicit transport constraint. `93ccb802ef` (#1508)
introduced launch-time OSC plus ongoing cmux renames, with the reason recorded
in its module comment: "writing alongside a native provider can split escape
frames." `173bb90880` (#1635) added tmux and viewer-owned host naming, but still
started name observation only when a supported host control channel existed.
No component serialized subsequent standard titles with provider bytes. Rex
therefore had no route from a stored Session rename to its terminal title.
This explains the generic-terminal gap without attributing it to a Rex defect.

The tests matched those implementation boundaries: string formatting,
attachment ownership and cmux workspace policy. In particular,
`taskless_name_is_preserved_without_terminal_controls` checks a formatting
function, not output to a terminal. A correct stored name and a passing host
policy test could coexist with no OSC rename being sent. The new terminal
owner/viewer test covers that previously missing path.

**Already implemented locally:** exclude `default`; publish standard titles
through the existing output owner and VT parser, between complete sequences,
with name reads off the I/O loop. The recorded tests cover rename, stale provider
title, split sequences and reattachment. The three disposable host observations
confirm receipt beyond the formatting layer. cmux/tmux retain their distinct
host controls. This supplies the common protocol path rather than adding another
terminal-specific publisher.

**Remaining verification, proposed for delivery:** when a disposable cmux server
is available, check initial title, rename, stale provider title and reattachment,
while preserving a manually named workspace. Passing policy tests do not prove
its displayed result. Keep Herdr's observed `terminal_title` separate from its
unchanged tab label `1`, and Rex's read API value separate from a generated-title
display preference. The evidence supports publication, not every layout showing
the same label. No global layout or preference changes are proposed.

The fallback still classifies generic skills by name; another generic skill could
reopen that small maintenance gap. A semantic skill-metadata redesign is not
justified by this incident alone. The bare-launch transport regression now checks
that the initial title is not `default`, alongside the focused fallback test.
For future title changes, keep one no-host protocol test as the common contract
and host tests for their additional controls; a full branded-terminal matrix
would add cost without addressing a different demonstrated cause.
