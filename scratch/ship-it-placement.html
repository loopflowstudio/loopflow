Where does Ship it go?

Three placements for the same action, clickable. Shipping runs a fake sequence (stand-in demo, gate, CI, a flake repair, the merge queue, merged) so you can watch each one carry the in-flight state. A shipped Task leaves the Working filter and shows up under Shipping.

All three: the state lives on the Task, Stop shipping is the undo (and disarms auto-merge), and a shipped Task drops out of the default Working view. These options are about where the button sits, not about what shipping does.
