# W2-88 — Wave Home: a user-owned execution address + the shared control path

## What shipped

A Wave's **Home** is a user-owned execution address — an *owner* plus a
*location* — that every surface resolves, probes, starts, and routes through one
shared Loopflow API. Not a host alias, not a local/remote boolean, not an lfd
daemon or a new Concerto protocol.

- **Address** (`engine/wave_home.rs`) — `WaveHome { owner, location }`.
  Canonical forms: `jack@local` and `ssh://jack@host[:port]`. Shorthand
  `jack@host` normalizes to the SSH URI. DNS, IPv4, bracketed IPv6, and optional
  ports flow through one `parse` funnel and one `Display` formatter. Owner is
  required (no implicit current-user Home) and distinct from credentials, which
  keep riding SSH + Doppler. Reachability is never enforced at parse time — a
  public IP, private/Tailscale DNS, and public host are the same location;
  whether it answers is operational evidence.

- **Control path** (`ops/home.rs`) — `probe_home` resolves a Wave→Home and
  classifies `Unreachable | Stopped | Running | Unknown` with a reason and, when
  running, the attach endpoint. Local Homes read the endpoint directly; remote
  Homes route `lf status --json` through the Home's SSH address
  (`ssh::capture_routed`). `start_home` is idempotent: it probes first and
  returns a running resident's identity instead of launching twice; a
  reachable-but-stopped Home is started **on the Home** (local: detached tmux
  `lf wave`; remote: the same over SSH), then re-probed for the attach identity.
  Everything routes through the Home address and the existing SSH/credential
  machinery — no surface reimplements SSH or owns a parallel lifecycle.

- **Evidence on the DTO** — `WaveSnapshot.home` carries the address (owner +
  structured location); `WaveDetailSnapshot.home_runtime` (`HomeRuntimeDto`)
  carries state + reason + attach endpoint + the one contextual `HomeAction`
  (Attach when running, Start on `<home>` when stopped, the reason otherwise).
  `lf status <wave>` probes the focused Wave; `lf ls` stays address-only (no
  per-wave SSH).

- **CLI** — `lf home probe <wave>` and `lf home start <wave>` (both `--json`)
  are the shared surface a conductor calls without implementing SSH.

- **Routing** (`lf/commands/home.rs`) — repo/PR/release/PM commands in a
  remote-home Wave forward over `lf ssh` (owner@host + port); `LF_HOME_ROUTED`
  breaks the forward loop. Local/absent Home runs in-process. Project/Task
  launches inherit the Home via `LF_WAVE_HOME`.

- **Status/transport** — `ssh` transport carries `owner@host` + `-p port` and a
  `capture_routed` variant for the probe. Swift mirrors the DTOs
  (`RegistryQuery.swift`) and the fixture round-trips; Swift never implements SSH
  or infers a host.

## Verified

- Unit: address parse/format for every form (local, DNS, IPv4, IPv6, port,
  shorthand), owner-required rejection, IPv6-must-be-bracketed; probe
  classification (running/stopped/null-registry/garbage→unknown); start session
  naming; DTO round-trips; routed preamble + `-p` port; `HomeAction` follows
  state.
- End-to-end with the built binary: `owner@host` routing forwards to the SSH
  destination (bounded fast-fail); local Home runs in-process; `lf home probe
  <wave>` prints `jack@local [stopped] → Start on jack@local` and the matching
  `--json` `HomeRuntimeDto`.

## Downstream (Mac Now / Roadmap task — not in this PR)

- **Conductor UI rendering** — the actual Open/Attach/Start button, Home
  navigation, and showing a Wave at `jack@local` / `ssh://jack@host`. The shared
  contract (`home` + `home_runtime` on the status DTO, `lf home probe|start
  --json`) is delivered; the pixels consume it. Replace
  `MacLocalWaveAgentLauncher`'s parallel tmux lifecycle with calls to `lf home
  start`.
- **Remote attach transport** — attaching to a remote resident's loopback
  endpoint needs an SSH tunnel; the shared API returns the identity (home +
  endpoint), the UI owns the tunnel.
- **Remote cold-start hardening** — the remote detached `lf wave` launch is
  constructed and unit-tested but not verified against a live host; the Cron-host
  bootstrap is where it earns live coverage.
- **Routable set** — still `pr/commit/rebase/release/pm`; grow deliberately.
