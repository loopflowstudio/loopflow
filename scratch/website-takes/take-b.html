Take B · contract-led

Break the work into phases. Let any agent finish it.

lf is the CLI your agents use to get work done. Each phase leaves its result on disk, so when an agent stops, the next one starts from there.

$ curl -fsSL https://loopflow.studio/install.sh | sh

The feature workflow. A login ran out during implement; the next agent read the design and the branch and kept going.

Every phase has a contract.

A phase is a Skill: a Markdown file in your repository that says what to do and what to leave behind. A Graph puts phases in order. Workflows say where you come in.

Nothing important lives only in an agent’s context. That is the whole trick: work that outlives your agents.

Write a Skill ↗Graphs ↗

# .lf/graphs/ship-api.yaml
- design      # leaves scratch/<task>.md
- implement   # leaves commits on the branch
- gate        # leaves passing checks
- ship        # leaves a pull request

Recovery is one command.

A crash

$ lf resume --all

Every conversation a restart interrupted comes back.

A spent login

$ lf account

Runs move to your next login when one runs out.

A stuck model

$ lf task run ETU-14 -a codex

Same Task, same branch, a different agent.

A busy laptop

$ lf --machine mini task run ETU-14

Run it on another of your machines over ssh.

With your team, too.

The Tasks are shared through Linear or a Git ref. Comment on one and its agent reads it before its next phase.
