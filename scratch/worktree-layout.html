Creates a tracked Task, prepares its checkout, and starts lf --task <issue> design. Project selection is still a design question. Your configured app or terminal owns the conversation. External conversations remain external; this sketch illustrates the terminal configuration.

New shell

Adds an ordinary terminal inside the selected worktree. Its process and working directory survive switching. A shell can run an agent too; the conversation must register against that existing terminal.
