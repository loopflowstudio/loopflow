Method and limits

Independent targets and cold-seeded caches. Cohort order alternates candidate/base, base/candidate. Edits have unique cohort suffixes. Two cold seeds are calibration and are excluded from the medians. Before the test-binary case, the owner's test binary and its dev-dependencies are built once outside the timing, then a second decoder message is edited. Profiles match. The registry dependency delta is 0 removed and 0 added version/checksum tuples. Machine: 16 logical CPUs, arm64, Darwin 25.0.0. Compiler: rustc 1.98.1 (48a229cea 2026-09-01) (Homebrew).

The sccache binary is pinned by SHA-256 863da74d6ada53050d5f4a220e77a16777fb863a4aaf44ea0c17f5f0e9577871; it needs Rust basedir and verbatim environment-dependency support, which 0.19.0 lacks. The root upkeep probe was not run for this comparison. No Machine cache configuration or shared daemon was changed.

The wrapper adds two statistics RPCs per workspace compiler; that overhead is included. CPU covers the timed client process tree, excluding the cache daemon. RSS is its largest process, not concurrent Machine memory. These observations do not establish total Machine CPU savings or a safe concurrency budget.

All 8 source copies passed runtime root/revision checks. Catalogue checks retained the canonical schema through Git reference and source-package changes. Retrieved rlibs can retain the seed checkout’s debug-source paths; use scripts/dev-lf --isolated-build when those paths no longer resolve.
