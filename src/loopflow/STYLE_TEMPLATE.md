# Project Style Guide

This document describes coding conventions and development practices for this project.

## Quick Reference

- Follow language-specific best practices
- Keep code simple and readable
- Write tests for new functionality
- Document complex logic

## Code Organization

Keep related code together. Use clear, descriptive names for files, functions, and variables.

## Testing

Write tests that verify user-facing behavior. Mock external dependencies but test real logic.

## Git Commits

Write clear commit messages that explain what changed and why.

## Documentation

Keep documentation close to code. Update docs when changing behavior.
