# Wave proof

The thesis demo: writing a goal is a way to compute — proven by waves that run
for real, not by a one-off build.

## KRs

- >= 5 waves run consistently for 1 week straight across Cadenza and loopflow.
- At least 2 waves on each codebase run from GOAL.md with zero repo-authored
  skills added for the work.
- 5/5 new wave starts produce a GOAL.md that passes the honest question before
  the first worker dispatch.
- Waves keep GOAL.md current — passing the honest question over time, not
  drifting into stale slogans.
