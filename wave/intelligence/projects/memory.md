# Memory

Loopflow retains the lessons that matter without growing a second brain. The
wave's memory is the compiled checkpoint that survives land, branch, machine,
and cold starts; the delta stream replays without becoming an archive.

## KRs

- No learning is lost across land, branch, machine move, or compaction.
- MEMORY.md answers "decided / constrained / in flight" at a glance and stays
  prompt-sized as facts accumulate indefinitely.
- The memory curation home is decided and implemented with one owner.
- Memory changes can point to a cited run trace or chat event that justified
  the retained fact.
