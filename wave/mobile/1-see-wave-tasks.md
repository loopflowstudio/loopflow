# See wave tasks

**Finish line:** Tap a wave to drill into its roadmap: scrollable list of items with priority badge + title. Tap any item to see its full content — markdown, code blocks, frontmatter. Read-only but rich.

## Context

Waves have roadmaps. The conductor's second habit: "what's on the plate for this wave?" The phone is where you check while walking or in a meeting.

## Daily experience

You saw `workflows` is blocked. Tap it. Roadmap shows 4 items: `daily-garden-cycle`, `continuous-build-loop`, `chat-session-api`, `pm-round-trip`. Tap `continuous-build-loop` to see the finish line and context. You now know what's at stake; you plan your afternoon accordingly.

## Done when

- Roadmap items render in priority order with title + badge
- Item detail renders full markdown (including code blocks)
- Frontmatter fields (dependencies, status) visible
- Navigation back to wave list + to attention from item detail
