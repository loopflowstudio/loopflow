# Mac Surface UX

The Mac app is the daily conductor surface for loopflow: glanceable wave state,
fast navigation, launch, reattach, steering, and audit views around the shared
product API.

## KRs

- The wave list makes the next required attention obvious.
- Launching, reattaching, steering, and inspecting a wave are one action from
  the main surface.
- The app's surface model is settled: primary list, detail, chat, audit, and
  terminal affordances each have one clear home.
- Mac UX exposes the shared loopflow API without Swift-owned parallel session
  lifecycle.
