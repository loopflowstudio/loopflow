# Proposals

Architectural simplifications that embody a design decision live here.

Statuses:

- `draft` - idea is forming, not yet backed by enough study.
- `prototyped` - throwaway spike has tested the risky part.
- `proposed` - ready for human design agreement.
- `approved` - agreed and ready to decompose.
- `queued` - execution items exist under `wave/reduce/queue/`.
- `done` - shipped.
- `rejected` - closed with rationale.

Dead code removal, mechanical dedup, rename/move work, and other changes that
do not embody a design decision do not need proposals.
