## Model (design settled)

Root is the conductor wave. It gardens the active waves and owns the order they move in; it does not own a product surface. Scope stays clean: concerto owns build-driving/chat UX, mobile owns the iOS read surface, workflows owns engine + PM sync + governance machinery, release owns cadence + updater + self-hosted cron deploy. Root owns only the relationships — the shared status vocabulary, and the schedule and posture of the garden/govern flows. Success is the morning garden ritual: open Concerto and get shipped, blocked, release health, cron-host health, mutation proposals, and human-decision items in one coherent pass with the next action clear.
